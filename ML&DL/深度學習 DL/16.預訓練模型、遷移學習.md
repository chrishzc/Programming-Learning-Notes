# 16. 預訓練模型與遷移學習

> [!ABSTRACT]
> 本篇筆記介紹深度學習中的預訓練模型（Pre-trained Models）與遷移學習（Transfer Learning）的核心概念。探討如何利用在大規模數據集（如 ImageNet）上訓練好的權重，快速適應新的目標任務，並深入說明特徵擷取（Feature Extraction）與微調（Fine-tuning）的實務步驟。

---

## 一、 預訓練模型 (Pre-trained Models)

在從頭訓練一個深層神經網路時，通常需要**極大的數據量**與**漫長的計算時間**。

- **什麼是預訓練模型？**：已經在大型公開數據集（例如包含 1400 萬張圖片、1000 個類別的 **ImageNet**）上訓練完成，並被研究人員分享出來的一組最優模型結構與權重參數。
- **超參數 vs 可訓練參數**：
  - **可訓練參數**：模型的權重（Weights）與偏差（Biases），預訓練模型提供了一組極佳的權重初始值。
  - **不可訓練參數（超參數）**：如學習率、批次大小（Batch Size）等，需由開發者手動設定。

---

## 二、 遷移學習 (Transfer Learning)

**遷移學習**是指將一個已經在來源領域（Source Domain）訓練好的模型，透過網路層的轉移與權重復用，應用到新的目標領域（Target Domain）的技術。

### 1. CNN 結構的拆解
在卷積神經網路中，模型通常可以清晰地拆分為兩個部分：
- **卷積基底 (Convolutional Base)**：由多組卷積層與池化層交替組成，主要目的為**特徵擷取 (Feature Extraction)**。
- **分類器 (Classifier)**：在卷積基底後面，使用全連接層（Dense）組成的網路，主要目的為**特徵分類**。

```
[輸入影像] ➔ [ 卷積基底 (凍結權重 / 特徵擷取) ] ➔ [ 全連接分類器 (重新訓練) ] ➔ [輸出類別]
```

### 2. 特徵層次與通用性 (Feature Hierarchy)
當 CNN 進行影像特徵擷取時，不同深度的層所學習到的特徵具有不同的通用性：
- **低階特徵（靠近輸入層）**：如邊緣、線條、顏色斑塊。這些特徵在大部分影像中皆通用，**通用性極高，非常適合直接遷移**。
- **高階特徵（靠近輸出層）**：如貓的耳朵、車輪等具體物體形狀。這些特徵與原始訓練集的種類高度相關。如果新任務與原任務差異很大，高階特徵則需要重新微調。

---

## 三、 微調 (Fine-tuning)

微調是指在遷移學習時，不只訓練新的分類器，同時也**解凍並微調卷積基底中的部分高階特徵層**，使模型更貼合新的目標數據。

### 1. 為什麼不從隨機初始化權重開始？
1. **防範過擬合**：小數據集從頭訓練極易過擬合，使用預訓練權重能起到正則化的效果。
2. **加速收斂**：預訓練模型已具備基本視覺特徵識別能力，微調能讓模型極快地收斂到較優的狀態。

### 2. 遷移學習與微調的實務步驟：
1. **移除原始分類器**：去掉預訓練模型最尾端針對原始任務設計的分類器。
2. **凍結卷積基底**：將卷積基底的參數設定為不可訓練（`trainable = False`），以保留其學到的通用特徵。
3. **加入自定義分類器**：在卷積基底後方連接全新的全連接層（分類器），並隨機初始化權重。
4. **訓練分類器**：先在新的數據集上訓練此分類器。
5. **解凍部分高階層（選用）**：若要進一步優化，解凍卷積基底靠近尾端的部分高階層。
6. **微小學習率訓練**：以**非常小的學習率**（避免破壞已學到的特徵）對解凍的層與分類器進行聯合訓練。

---

## 四、 Keras Applications 實作範例

TensorFlow 的 `keras.applications` 模組提供了許多經典的預訓練模型（如 VGG16, ResNet50, MobileNet 等）。以下為使用 VGG16 進行特徵擷取與分類器訓練的範例：

```python
"""
File: keras_transfer_learning.py
Description: 使用 TensorFlow Keras 載入預訓練 VGG16 進行遷移學習的實作程式碼
"""
import tensorflow as tf
from tensorflow.keras import layers, models
from tensorflow.keras.applications import VGG16

# 1. 載入預訓練的 VGG16 卷積基底 (不含最上層全連接分類器 include_top=False)
conv_base = VGG16(weights='imagenet', include_top=False, input_shape=(150, 150, 3))

# 2. 凍結卷積基底的所有權重參數
conv_base.trainable = False

# 3. 搭建自定義模型，將預訓練基底與新的分類器連接
model = models.Sequential([
    conv_base,                             # 預訓練的特徵擷取層
    layers.Flatten(),                      # 展平層
    layers.Dense(256, activation='relu'),   # 自定義特徵整合層
    layers.Dropout(0.5),                    # 防止過擬合
    layers.Dense(1, activation='sigmoid')   # 二分類輸出層 (例如: 貓/狗分類)
])

# 4. 編譯模型 (此時只有 Dense 層的權重會被計算與更新)
model.compile(optimizer='rmsprop',
              loss='binary_crossentropy',
              metrics=['accuracy'])

# 5. 印出網路架構
model.summary()
```
