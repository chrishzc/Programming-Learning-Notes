## 一、 自然語言處理 (NLP) 與詞表示

自然語言處理 (Natural Language Processing, NLP) 是 AI 的核心領域之一，旨在讓電腦能夠理解與處理人類語言。

- **非結構化挑戰**：人類文字（如文章、對話）是非結構化資料，電腦無法直接進行數學運算。
- **詞表示 (Word Representation)**：必須將文字轉換為數值向量，這個將文本轉化為結構化數值資訊的過程即為詞表示。
- **相似度衡量**：通常使用 **餘弦相似度 (Cosine Similarity)** 來計算兩個詞向量在空間中的夾角餘弦值，藉此衡量詞義的相近程度。其公式為：
  $$\text{Cosine Similarity}(\mathbf{a}, \mathbf{b}) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \|\mathbf{b}\|}$$

## 二、 常見的詞表示方法

### 1. 獨熱編碼 (One-hot Encoding)
將詞彙表中的每個單詞表示為一個維度等於詞彙量（Vocabulary Size）的稀疏向量，該單詞對應的索引位置值為 `1`，其餘位置均為 `0`。

- **範例**：給定句子 `"I am a Software engineer and I like programming languages"`
  詞彙表（9 個不重複單詞）：`['I', 'am', 'a', 'Software', 'engineer', 'and', 'like', 'programming', 'languages']`
  - `"I"` ➔ `[1, 0, 0, 0, 0, 0, 0, 0, 0]`
  - `"am"` ➔ `[0, 1, 0, 0, 0, 0, 0, 0, 0]`
- **缺點**：
  1. **維度災難與稀疏性**：詞彙量極大（如數十萬詞）時，向量維度極高且其餘全是 `0`，極度浪費運算空間與記憶體。
  2. **缺乏語義相關性**：任何兩個不同單詞的向量內積均為 `0`，無法利用餘弦相似度表現詞彙之間的關聯程度（例如 "king" 與 "queen" 在 one-hot 空間中是完全正交的）。

---

### 2. 整數編碼 (Integer Representation)
為詞彙表中的每個單詞分配一個唯一的整數 ID，並將整句話表示為整數序列（List）。

- **範例**：
  - `"I"` ➔ `1`, `"am"` ➔ `2`, `"a"` ➔ `3`
  - 句子 `"I am a"` ➔ `[1, 2, 3]`
- **缺點**：
  - 雖然降低了維度，但整數的大小關係會誤導模型（例如模型可能會認為編碼為 `3` 的詞比 `1` 更重要，或者 `3` 與 `2` 的距離比 `3` 與 `1` 更近），且完全無法表達詞與詞之間的語義親疏關係。

---

### 3. 詞嵌入 (Word Embedding)
詞嵌入將高維度的稀疏詞向量，對應/嵌入到一個**低維度的稠密實數空間**中（通常為 50 到 300 維）。

- **核心優勢**：
  1. **低維稠密**：將數萬維的稀疏 one-hot 降維至固定低維度的連續實數向量。
  2. **捕捉語義**：語義相近的單詞在嵌入空間中的距離會非常接近（餘弦相似度高），可表達如「$\mathbf{v}_{\text{king}} - \mathbf{v}_{\text{man}} + \mathbf{v}_{\text{woman}} \approx \mathbf{v}_{\text{queen}}$」的關係。

#### 常用詞嵌入演算法：
1. **Word2Vec (2013年由 Google 的 Mikolov 團隊提出)**
   - **CBOW (Continuous Bag-of-Words)**：利用上下文（周圍的詞）來預測當前詞。相當於一句話挖空一個詞，讓模型去猜。
   - **Skip-gram**：利用當前詞來預測上下文（周圍的詞）。相當於給定一個詞，猜它前後可能出現什麼詞。
2. **GloVe (Global Vectors for Word Representation)**：結合了全域共現矩陣（Matrix Factorization）與 Word2Vec 的局部上下文滑動視窗優點。

## 三、 TensorFlow Keras 實作 Word Embedding

在 Keras 中，我們可以透過 `layers.Embedding` 層快速實現詞嵌入。該層相當於一個**可學習的查詢表（Lookup Table）**，能將整數索引映射為稠密向量。

```python
"""
File: word_embedding_demo.py
Description: 使用 TensorFlow Keras 建立並訓練 Word Embedding 層的實作程式碼範例
"""
import numpy as np
import tensorflow as tf
from tensorflow.keras import layers, models

# 1. 模擬輸入數據：3 句話，每句話已被填充/截斷為長度 4 的整數序列
# 詞彙表大小 (vocab_size) 設為 10
vocab_size = 10
embedding_dim = 4  # 將每個單詞嵌入到 4 維空間

# 模擬的輸入 (批次大小 batch_size = 3, 句子長度 input_length = 4)
input_data = np.array([
    [1, 2, 3, 4],
    [1, 5, 6, 0],
    [7, 8, 9, 0]
])

# 2. 建立包含 Embedding 層的模型
model = models.Sequential()
model.add(layers.Embedding(input_dim=vocab_size, output_dim=embedding_dim, input_length=4))

# 3. 編譯並預測輸出
model.compile('rmsprop', 'mse')
output = model.predict(input_data)

print("輸入資料形狀:", input_data.shape)    # (3, 4)
print("輸出資料形狀:", output.shape)        # (3, 4, 4) -> (Batch, Sequence_length, Embedding_dim)
print("\n第一個句子的 Word Embedding 向量:\n", output[0])
```
