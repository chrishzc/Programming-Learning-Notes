# LangGraph Studio 視覺化 IDE

> [!ABSTRACT]
> 本章介紹 LangGraph Studio —— 專為 AI Agent 工作流打造的視覺化整合開發環境（IDE），深入探討其三大核心功能（狀態監控、時光旅行、人機協作）與本機快速開發配置指南。

---

## 1. 什麼是 LangGraph Studio？

**LangGraph Studio** 是由 LangChain 官方推出，專為 AI Agent（智慧體）工作流打造的**視覺化整合開發環境（IDE）**。

如果說 LangGraph 是讓你用程式碼定義複雜 AI 邏輯的「引擎」，那麼 LangGraph Studio 就是你的「儀表板」與「控制台」。它解決了過去開發 Graph-based（基於圖形架構）Agent 時，難以測試、難以除錯、難以觀察 State（狀態）變化的痛點。

---

## 2. 🚀 三大殺手級功能 (Key Features)

### 2.1 即時圖形化架構與狀態監控
- **架構自動同步**：只要在本機修改程式碼中的 Node（節點）或 Edge（連線），Studio 介面就會即時重新渲染出最新的架構圖。
- **執行節點高亮**：當你送出測試提示詞（Prompt），圖上的節點會隨之閃爍、亮起，你可以肉眼直觀看到 Agent 目前「走到了哪一步」。

### 2.2 「時光旅行」與狀態編輯 (Time Travel & State Editing)
這是開發複雜 Agent 最強大的功能之一：
- **任意回溯**：Agent 跑了 10 個步驟後，如果第 8 步的 LLM 答錯了，你不需要重新從第 1 步開始執行。你可以直接點擊第 7 步的歷史紀錄。
- **插手修改**：你可以直接在 UI 上手動修改當前的 `State`（全域狀態資料）或編輯大模型的 Prompt，然後點擊「重試」，Agent 就會從該節點依據你修改後的資料繼續往下跑。

### 2.3 原生支援人機協同 (Human-in-the-loop)
- 當你的 Graph 中設有中斷點（Interrupt，例如金流支付需要人工確認、或是敏感代碼需要人工審核），LangGraph Studio 會在執行到該節點時自動暫停，並在 UI 上跳出「核准 (Approve)」或「拒絕 (Reject)」的按鈕，讓你完美模擬真實的人機互動場景。

## 3. 🛠️ 開發環境快速配置指南 (Quick Setup)

要讓 LangGraph Studio 在本機運行，你需要準備三個核心元件：

```
[LangGraph 程式碼] + [langgraph.json 配置文件] ──> 由 [LangGraph CLI] 透過 Docker 啟動 Studio
```

### 3.1 專案目錄結構

在你的專案資料夾中，除了主要的 Agent 程式碼之外，必須包含一個 `langgraph.json` 配置文件：

```text
my-agent-project/
├── agent.py          # 撰寫 workflow.compile() 的主程式
├── requirements.txt  # 依賴套件
└── langgraph.json    # Studio 的關鍵配置文件
```

### 3.2 撰寫 `langgraph.json`

這個檔案是用來告訴 Studio 要去哪裡載入你的 Graph。

```json
{
  "dependencies": ["."],
  "graphs": {
    "my_agent": "./agent.py:app"
  },
  "env": ".env"
}
```

> [!TIP]
> 指向路徑 `./agent.py:app` 代表載入 `agent.py` 檔案中名為 `app` 的編譯後圖形物件（即 `app = workflow.compile()`）。

### 3.3 啟動 Studio

目前 LangGraph Studio 主要是透過 `langgraph-cli` 配合 **Docker** 在本機運行後台服務（Studio 會在 Docker 中建立獨立的隔離環境）。

在終端機執行以下指令：

```bash
# 1. 安裝 LangGraph 命令行工具
pip install langgraph-cli

# 2. 在包含 langgraph.json 的目錄下啟動 Studio 伺服器
langgraph dev
```

啟動成功後，終端機會提供一個本機網址（通常是 `http://localhost:3000` 或是由官方提供的 Web 介面引導連結），打開後就能直接進入視覺化工作室！
