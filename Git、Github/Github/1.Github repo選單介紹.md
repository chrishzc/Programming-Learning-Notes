# GitHub Repository 頁籤總覽

> [!ABSTRACT]
> 本篇整理 GitHub Repository 上方導覽列各個頁籤的核心功能與使用場景，幫助新手快速掌握每個區域的用途。

---

## 一、 主要功能頁籤

*   **📁 Code（程式碼）**：瀏覽專案的所有程式碼檔案與資料夾結構。下方會自動渲染 `README.md` 作為專案說明書。右上角的綠色 `Code` 按鈕可下載 ZIP 或取得 Clone 網址。

*   **❓ Issues（議題）**：提交 Bug 回報、新功能建議或任何代辦事項的追蹤清單。每個 Issue 可以指派負責人（Assignees）、貼上分類標籤（Labels）並連結到里程碑（Milestones）。

*   **🔀 Pull Requests（PR）**：開發者完成功能後，申請將自己的分支合併回主分支的審查平台。團隊成員在此進行 Code Review，確認無誤後才執行 Merge。

*   **⚙️ Actions（自動化）**：設定 CI/CD 自動化流水線。每次 Push 或提出 PR 時，可以自動觸發測試、格式檢查、部署等工作流程（Workflow），結果以 🟢 / 🔴 顯示。

*   **📊 Projects（專案看板）**：將 Issues 和 PR 整理成看板（Kanban）、時間軸或表格視圖，進行任務的進度管理。

*   **🛡️ Security（安全）**：自動掃描專案依賴套件的已知安全漏洞，並提醒是否有將 API Key 或密碼等敏感資訊暴露在程式碼中。

*   **📈 Insights（數據分析）**：查看專案的統計資料，包含各成員的 Commit 次數、程式碼新增/刪除量、流量來源、Stars 與 Forks 趨勢等。
