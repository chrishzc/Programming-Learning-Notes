# GitHub Copilot Agent 頁面功能介紹

> [!ABSTRACT]
> 本篇說明 GitHub 的 Copilot Agent（Agents 頁籤）功能，包含 Agent Session 的用途、畫面狀態說明以及 AI 自主工作的操作流程。

---

> [!NOTE]
> 此頁籤只有在啟用 GitHub Copilot 並實際指派任務給 AI Agent 後，才會出現活躍的 Session 紀錄。

---

## 一、 Agents 頁面是什麼？

GitHub Copilot Agent 是一個可以自主執行多步驟任務的 AI 工作者。與一般 Copilot 的「逐行建議」不同，Agent 可以接受一段高層次的任務描述（如「幫我找出所有登入相關的 Bug 並修復」），然後**自主瀏覽程式碼、開分支、撰寫程式、提交 PR**，最後等待你審核。

Agents 頁面就是追蹤這些 AI 工作 Session 進度的面板。

---

## 二、 頁面狀態說明

*   **`No sessions match your filters`**：預設篩選條件為 `is:open author:@me`（只顯示你自己開啟中的 Agent Session）。若頁面顯示為空，代表目前沒有進行中的 Agent 任務。

*   **`Status` / `Type` / `Agent` 篩選器**：當有多個 AI 任務同時進行時，可用這些篩選器過濾出特定狀態的 Session：
    *   `Active`：AI 正在執行中的任務。
    *   `Completed`：已完成並等待你審核的任務。
    *   `Failed`：執行失敗或被中斷的任務。

---

## 三、 Agent 任務的執行流程

1.  在 Issues 頁面找到你想要 AI 處理的議題，點擊指派給 Copilot。
2.  Agent 接手任務後，會自動在 `Agents` 頁面建立一個新的 Session。
3.  Session 進行中，AI 會自主閱讀 Code、建立 PR 或提出修改建議。
4.  任務完成後，你在 PR 頁面審查並決定是否 Merge。
