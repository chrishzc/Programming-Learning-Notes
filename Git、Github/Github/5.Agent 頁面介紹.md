==如果使用coplite有產生任務時才會用到這個頁面==

### 1. 畫面的核心現況

- **「No sessions match your filters」**
    
    - **物理畫面想像**：這是辦公室的「AI 專屬工作日誌」。
        
    - **為什麼現在是空的？**：因為你目前的搜尋框被設定了 `is:open author:@me`（只顯示「我自己發起且正在進行中」的 AI 對話）。此時此刻，你還沒有跟這座大樓的 AI 助理展開過任何對話或下達任務，所以工作日誌上才沒有任何紀錄。
        

---

### 🤖 2. Agents 頁面的作用是什麼？（畫面因果關係）

在這個辦公室裡，你不是自己苦哈哈地敲程式碼，而是像一個「高階指揮官」，用大白話對 AI 下命令：

- **發派複雜任務（Sessions 畫面的由來）**： 未來如果你在這裡開啟一個新的 Session（對話對接），你可以對 AI Agent 說：「_幫我把這棟大樓的所有漏水 Bug 找出來並修好_」或是「_幫我寫一個自動發送警報的程式碼_」。
    
- **自主動工與回報（動態變化）**： 這個 AI Agent 拿到任務後，會自己去翻閱大樓的材料架（Code）、看意見箱（Issues），然後**自己動手開分支、寫程式碼，甚至自己提交 PR（施工變更申請）** 給你審核！
    
- **進度追蹤（上方那排小標籤）**：
    
    - `Status` / `Type` / `Agent`：當你有好幾個 AI 機器人同時在幫你寫不同的功能時，你可以用這排按鈕過濾出「哪幾個 AI 已經完工了（Completed）」、或是「目前有哪幾隻 AI 正在幫我查資料（Active）」
