# GitHub Code 頁面功能介紹

> [!ABSTRACT]
> 本篇整理 GitHub Code 頁面中，Repo 層級的操作按鈕（Pin / Watch / Fork / Star）以及進入 Repo 後的介面功能（分支切換器、檔案列表、最新提交狀態欄、Code 下載按鈕）說明。

---

## 一、 Repo 層級操作（個人 Profile 或 Explore 頁面）

*   **📌 Pin（釘選）**：將此 Repo 固定顯示在你個人 Profile 首頁的最上方，方便快速存取常用專案。

*   **👁️ Watch（訂閱通知）**：設定這個 Repo 的事件通知策略。
    *   `Participating`：只有被 @提及 或你直接參與的討論才通知。
    *   `All Activity`：Repo 內任何 Issue、PR、留言都推播通知。
    *   `Ignore`：完全靜音。

*   **🍴 Fork（分叉複製）**：將整個 Repo 連同所有歷史紀錄複製一份到自己的帳號下。Fork 出的版本完全獨立，可以自由修改，修改完後可透過 Pull Request 回饋給原專案。

*   **⭐ Star（收藏點讚）**：相當於「我的最愛」。Star 數量是衡量一個開源專案受歡迎程度的指標，你也可以在個人的 Starred 清單中找回收藏的 Repo。

---

## 二、 Repo 內部介面功能

*   **🌿 分支切換器（左上角）**：顯示當前所在分支（預設為 `main`）。點開後可切換至其他分支或 Tag，瀏覽不同版本的程式碼狀態。

*   **🗂️ 檔案與目錄列表（中央區塊）**：以表格形式列出所有資料夾與檔案。每一列除了名稱之外，還會顯示：
    *   **Last commit message**：該檔案最後一次被修改時的 commit 訊息。
    *   **Last commit date**：最後修改的相對時間（如「3 days ago」）。

*   **⏱️ 最新提交狀態欄（檔案列表上方）**：顯示整個分支最新一次 commit 的作者、訊息摘要與 Commit Hash（例如 `6cbb452`）。點擊 Hash 可查看該次 commit 的完整代碼差異（Diff）。

*   **🟩 綠色 Code 按鈕（右上角）**：提供多種取得程式碼的方式：
    *   **Clone**：複製 HTTPS 或 SSH 網址，在本地執行 `git clone` 使用。
    *   **Open with GitHub Desktop**：用 GitHub Desktop 客戶端直接開啟。
    *   **Download ZIP**：打包下載整個專案（不含 Git 歷史紀錄）。
    *   **`Go to file`**：快速搜尋 Repo 中任何檔案名稱，瞬間定位目標檔案。
