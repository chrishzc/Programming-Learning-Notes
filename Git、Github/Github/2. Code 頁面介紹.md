# Repo選項
### 1. 📌 Pin（釘選最愛專案 / 快速通行證）

- **畫面想像**：這是一面你個人專屬的「常用佈告欄」。GitHub 上有成千上萬個工程，你在自己家首頁的顯眼處釘上這顆圖釘。
    
- **核心功能**：
    
    - **快速傳送門**：點下 `Pin` 後，這個專案就會被固定在你個人 Profile（個人主頁）的最上方。下次你一登入，不用在茫茫大海中搜尋，一眼就能看到它，直接點進來開工。
        

### 2. 👁️ Watch（裝設即時對講機 / 監控警報器）

- **畫面想像**：你戴上了一副無線對講機，並把頻道調到這座大樓。只要大樓裡有任何風吹草動（有人吵架、提意見、改設計圖），你的對講機就會立刻「嗶嗶嗶」響起。
    
- **核心功能**：
    
    - **接收通知**：你可以選擇關注的程度：
        
        - _Participating_：只有當別人提到你（@你）或你參與討論時才通知。
            
        - _All Activity_：這棟大樓發生任何事（開 Issue、改 Code、留言）通通發簡訊/Email 通知你。
            
        - _Ignore_：完全靜音，世界和平。
            

### 3. 🍴 Fork（影分身之術 / 複製整棟大樓回自家土地）

- **畫面想像**：你覺得這棟大樓的設計太讚了，想在裡面加個私人游泳池，但直接在人家的土地（原專案）上亂挖會被工頭打。於是你施展「影分身之術」，**把整棟大樓連同所有設計圖，一模一樣地複製一份，平移到你自己的私人土地上**。
    
- **核心功能**：
    
    - **自由改造**：在 Fork 出來的複製品裡，你是至高無上的國王，可以隨便改、隨便亂寫，完全不會影響到原本的那棟大樓。如果你改完覺得「哇！我加的游泳池太棒了，原作者應該也會喜歡」，你就可以透過前面提過的 **Pull Request（施工變更申請）**，把這個改動申請合併回原本的大樓。
        

### 4. ⭐ Star（幫優良施工團隊點讚 / 給星星收藏）

- **畫面想像**：你在大樓門口貼上一張「優良模範工程」的貼紙，並把它放進你的私人「旅遊口袋名單」裡。
    
- **核心功能**：
    
    - **點讚與收藏**：它就像是臉書的按讚，或者是瀏覽器的「我的最愛」。星星越多代表這個專案在世界上越受歡迎。未來你想找這份設計圖時，只要翻開你個人的「星級收藏清單」，就能瞬間找到它。
# Repo內容
### 1. 🌿 分支切換器（平行宇宙切換鈕）

- **畫面上長這樣**：通常在左上角，有一個像分支箭頭的圖標，預設寫著 `main` 或 `master`。
    
- **物理畫面想像**：這是一台「平行宇宙切換機」。大樓的正式主體在主時空（`main`），但工人們為了不弄壞主體，會複製一個平行時空（例如：開發新功能的 `feat/cli` 分支）。
    
- **怎麼看**：點開它，你就能切換去參觀別人在平行時空裡蓋到一半的大樓。
    

### 2. 🗂️ 檔案與目錄列表（建材與設計圖架）

- **畫面上長這樣**：佔據螢幕中央最大區塊的表格，一列一列的資料夾（如 `.agents`、`adad_cli`）和檔案（如 `README.md`、`pyproject.toml`）。
    
- **物理畫面想像**：這是總部的「材料分類架」，每一層都貼著標籤：
    
    - **資料夾（藍色圖標）**：代表一整箱的分類建材（例如 `docs` 裡全都是施工說明書）。
        
    - **單一檔案（文件圖標）**：代表單一設計圖或設定檔（例如 `LICENSE` 是法律授權書）。
        
- **後面的小字代表什麼？**
    
    - **Last commit message（最後動工筆記）**：例如畫面上寫著 `system_map format upgrade`，這代表這箱材料最後一次被移動時，工人隨手貼上的「施工備忘錄」，告訴你他剛才動了什麼。
        
    - **Last commit date（最後動工時間）**：告訴你這箱材料是「1 小時前」剛搬來的新貨，還是「上週」就放在這裡的老古董。
        

### 3. ⏱️ 最新提交狀態欄（工頭的施工日誌紀錄）

- **畫面上長這樣**：在檔案列表正上方的一條橫欄，左邊有施工人員的頭像，右邊有一串神祕的英文數字代碼（例如 `6cbb452`）。
    
- **物理畫面想像**：這是大螢幕上的「最新動態跑馬燈」。
    
- **核心功能**：
    
    - **是誰動的？**：顯示最後一個動這層架子的人（例如 `chrishzc`）。
        
    - **施工編號（Commit Hash）**：那一串神祕代碼（`6cbb452`）就是這次施工的「歷史快照編號」。點下去，就像按下錄影帶的「回放鍵」，大腦畫面會立刻切換到**這一次施工中，他到底多加了哪幾行程式碼、刪了哪幾行程式碼（紅綠色的代碼差異比對）**。
        

### 4. 🟩 綠色 Code 按鈕與功能列（進貨與打包傳送門）

- **畫面上長這樣**：右上角醒目的綠色 `Code` 按鈕，以及旁邊的 `Go to file`、`Add file`。
    
- **物理畫面想像**：這是總部的「物資出入口」。
    
    - **`Go to file`（材料快速搜尋放大鏡）**：當材料架太大，你按這顆鈕輸入關鍵字（例如輸入 `install`），系統就會像偵探一樣幫你把 `install.py` 從幾千個檔案裡瞬間抓出來。
        
    - **綠色 `Code` 按鈕（打包傳送門）**：點開它，它會提供你下載整座大樓設計圖的幾種方法。最直接的就是最下面的 `Download ZIP`，點下去，整棟大樓的材料就會被壓縮成一個懶人包，直接傳送到你的電腦裡。
