# GitHub Issues 頁面功能介紹

> [!ABSTRACT]
> 本篇整理 GitHub Issues 頁面的各項功能，包含頂部篩選器、建立 Issue 時的選項欄位，以及左側欄的個人快捷區與全局管理區說明。

---

## 一、 頂部搜尋篩選列

Issues 頁面頂部有一個搜尋輸入框，預設內容為 `is:issue state:open`（顯示所有未關閉的議題）。

*   `is:issue`：只顯示 Issues，排除 PR。
*   `state:open` / `state:closed`：篩選未關閉 / 已關閉的議題。
*   加入關鍵字（如 `is:issue state:open 登入失敗`）可進一步全文搜尋相關 Issue。

---

## 二、 建立新 Issue（New Issue）

點擊右上角的綠色 `New issue` 按鈕後，在編輯頁面可設定以下欄位：

*   **👥 Assignees（指派負責人）**：決定由誰負責處理這個 Issue，可指派自己或其他團隊成員。一目了然誰在負責，避免重複作業。

*   **🏷️ Labels（分類標籤）**：為 Issue 貼上分類標籤，例如：
    *   `bug`（紅色）：程式發生錯誤。
    *   `enhancement`（藍色）：功能改善或新增需求。
    *   `documentation`：文件相關。

*   **🗂️ Projects（連結專案看板）**：將此 Issue 加入指定的 Project 看板，讓它出現在進度管理視圖中。

*   **🎯 Milestone（里程碑）**：將 Issue 歸屬至某個版本目標（如 `v1.0`）。Issue 解決後，里程碑的整體進度條會自動更新。

---

## 三、 Open / Closed 狀態分頁

*   **🟢 Open**：目前尚未解決、仍在處理中的議題。
*   **🔴 Closed**：已解決或手動關閉的歷史議題。點進去可以查閱過去如何解決類似問題，是很好的參考資源。

---

## 四、 左側欄功能

### 個人快捷區
*   **Assigned to me**：所有指派給自己的 Issues，等同個人工作清單。
*   **Created by me**：自己建立的所有 Issues，方便追蹤進度。
*   **Mentioned**：其他人在 Issue 中 @提及你的所有討論紀錄。
*   **Recent activity**：你最近互動過（留言或查看）的 Issues 清單。

### 全局管理區
*   **Views**：切換 Issues 的顯示方式（如表格、看板等不同視圖）。
*   **Projects**：直接連結到 GitHub Projects 看板，查看議題在整個專案中的進度位置。
*   **Milestones**：查看各里程碑的完成進度（已完成 Issues 數 / 總數）。
*   **Labels**：管理專案中所有標籤的顏色與名稱定義。
