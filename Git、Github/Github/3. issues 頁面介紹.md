# Issues 頁面
### 1. 🔍 頂部搜尋篩選列（萬能任務搜尋引擎）

- **畫面上長這樣**：上方有一個長條輸入框，預設會寫著 `is:issue state:open`。
    
- **物理畫面想像**：這是一台「任務篩選跑馬燈」。畫面上那串像咒語的字，其實是大白話：
    
    - `is:issue`：只要看「問題與建議」，不要混到其他東西。
        
    - `state:open`：只顯示「目前還沒解決、還在處理中」的任務。
        
- **核心功能**：如果你想找特定任務，可以在後面空一格，輸入關鍵字（例如 `is:issue state:open 登入失敗`），它就會像磁鐵一樣，把所有跟登入失敗有關的便利貼通通吸出來。
    

### 2. 🟢 綠色 New Issue 按鈕（提交新任務單）

- **畫面上長這樣**：右上方醒目的綠色按鈕 `New issue`。
    
- **物理畫面想像**：這是總部的「意見箱投遞口」。
    
- **核心功能**：當你發現程式有 Bug（漏水）或是想提新點子（加蓋陽台），點下這顆鈕，系統就會發給你一張空白黃色便利貼。你可以在上面寫下標題、詳細狀況，甚至貼上螢幕截圖，按下送出後，這張便利貼就會掛到廣場中央讓大家看見。
    
#### 創建時的選項
- **👥 Assignees（指派負責人）**
    
    - **畫面想像**：在任務卡片上貼上「施工人員的大頭貼」。
        
    - **核心功能**：決定「誰來動手做」。你可以點擊齒輪把自己或團隊成員的名字掛上去，讓大家一目了然這項工作現在是誰在負責，避免多個人重複重複做同一件事。
        
- **🏷️ Labels（分類標籤）**
    
    - **畫面想像**：在任務卡片上貼上「五顏六色的分類貼紙」。
        
    - **核心功能**：決定「這是什麼種類的任務」。例如：新功能就貼藍色的 `enhancement`（功能優化），程式出錯就貼紅色的 `bug`。這能讓大家在公海裡一眼看出任務的屬性。
        
- **🗂️ Projects（專案進度看板）**
    
    - **畫面想像**：將任務卡片隔空拍到中央大白板的「待辦事項（To Do）」格子裡。
        
    - **核心功能**：決定「目前的施工狀態」。把這張卡片放進專案白板後，它就會隨著開發進度，被經理或工程師手動往右拖移到「正在做（In Progress）」或「做完了（Done）」。
        
- **🎯 Milestone（里程碑 / 施工大期程）**
    
    - **畫面想像**：將任務卡片綁定到大樓外牆的「重大驗收期程告示牌」上。
        
    - **核心功能**：決定「這項任務的完工期限」。當你把卡片歸類到某個里程碑（例如：`第一階段驗收`）後，只要這張卡片被解決（Closed），該里程碑的整體進度條就會自動往右前進一格。

### 3. 📑 狀態分頁標籤（進行中與已完成的任務堆）

- **畫面上長這樣**：在列表左上方，寫著 `🟢 Open`（綠色圓圈）和 `🔴 Closed`（紅色打勾圓圈），後面帶著數字。
    
- **物理畫面想像**：這是廣場上的兩個「大任務籃」。
    
    - `Open`：代表**正在施工、待解決**的任務。
        
    - `Closed`：代表**已經修好、結案**的歷史紀錄。點進去可以翻閱過去別人是怎麼解決類似問題的（這往往是工程師的藏寶庫！）。
        

### 4. 🏷️ 任務列表與過濾小標籤（卡片分類夾）

- **畫面上長這樣**：點進去後，中間會有一條條的任務標題，右邊通常有 `Author`、`Labels`、`Milestones`、`Assignee` 等下拉選單。
    
- **物理畫面想像**：這是幫卡片分類的「圖章與負責人名牌」：
    
    - **Author（提案人）**：過濾出是誰貼這張便利貼的。
        
    - **Labels（分類標籤）**：每張卡片上會貼有五顏六色的小貼紙。例如 `bug`（紅色，代表出錯了）、`enhancement`（藍色，代表功能優化）。你可以點擊標籤，只看全場的紅色 Bug 卡片。
        
    - **Assignee（負責人）**：這張卡片指派給誰去修理，卡片右側會出現那個人的大頭貼。
        
    - **Milestones（里程碑）**：這代表大樓的「階段性工期」（例如：預計 1.0 版本要完工）。把這張卡片歸類到某個工期裡，大家就知道它要在什麼時候前做完。

# 左側其他欄位
### 1. 「快捷抽屜」

- **👤 Assigned to me（指派給我的任務）**
    
    - **物理畫面想像**：這是你的「個人工作清單」。點下去，廣場上所有貼著你名字大頭貼、需要你動手修理的便利貼，會通通被打包到你面前。
        
- **😊 Created by me（我提的意見/回報）**
    
    - **物理畫面想像**：這是你的「發言紀錄簿」。點下去，只會顯示你過去跟工頭抱怨過的 Bug（漏水）或是提過的新功能建議，方便你追蹤工頭到底修好了沒。
        
- **＠ Mentioned（點名到我的討論）**
    
    - **物理畫面想像**：這是一個「點名通知欄」。當別人在其他任務的留言板上大喊「@你的名字，這部分你怎麼看？」時，這些點名你的卡片就會通通收納在這裡，讓你不會漏掉任何對話。
        
- **⏱️ Recent activity（最近的動態）**
    
    - **物理畫面想像**：這就像是你最近翻閱過的「歷史瀏覽紀錄」，幫你快速連回你剛剛看過、或剛留過言的那幾張任務卡片。
        

---

### 2. 「全局抽屜」

這一區則是從整個工程的「管理視角」出發，幫團隊把卡片做更有系統的歸類：

- **📦 Views（視圖切換）**
    
    - **物理畫面想像**：這讓你可以切換看任務的方式，像是把清單換成表格或不同的排列組合。
        
- **🗂️ Projects（專案進度看板）**
    
    - **物理畫面想像**：點下去會直接連結到我們最一開始提到的「待辦事項白板（To Do / In Progress / Done）」，讓你看這些 Issues 在整個大工程裡被排在什麼進度位置。
        
- **🎯 Milestones（里程碑 / 施工進度條）**
    
    - **物理畫面想像**：這是一條「時間軸進度表」（例如：預計 7 月底要發布 2.0 版本）。點進去，你會看到距離 2.0 完工還剩下多少張 Issues 沒解決，進度條跑到了百分之幾。
        
- **🏷️ Labels（標籤大熔爐）**
    
    - **物理畫面想像**：這是一整箱「五顏六色的標籤貼紙庫」。點進去可以看到這個專案定義了哪些標籤（如：紅色是 `bug`、藍色是 `feature`），你可以在這裡管理、修改這些標籤的顏色和名字。
