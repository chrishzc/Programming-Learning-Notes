# 顯示檔案內容（cat / tac / nl）

## cat（concatenate）

顯示檔案內容，也可用來顯示「從鍵盤輸入的內容」。

```bash
# 執行 cat，然後輸入字串（可多行），按下 Ctrl+D 送出結束符號
cat
```

| 指令範例 | 說明 |
|----------|------|
| `cat file1` | 顯示 `file1` 內容 |
| `cat -b file1` | 顯示行號，**僅針對非空白行** |
| `cat -n file1` | 顯示行號，**連同空白行** |

## tac（反向顯示）

```bash
tac file1   # 反向顯示 file1（從最後一行到第一行）
```

## nl（顯示行號，效果同 `cat -b`）

```bash
nl file1
```

# 顯示檔案頭尾內容（head / tail）

## head（顯示前面的行數）

| 指令範例                | 說明                    |
| ------------------- | --------------------- |
| `head file1`        | ==預設顯示前 10 行==        |
| `head -n 20 file1`  | 顯示前 20 行              |
| `head -n -40 file1` | 顯示**除了最後 40 行以外**的所有行 |

## tail（顯示最後幾行）

| 指令範例                | 說明                   |
| ------------------- | -------------------- |
| `tail file1`        | ==預設顯示末 10 行==       |
| `tail -n 20 file1`  | 顯示末 20 行             |
| `tail -n +50 file1` | 顯示**除開頭 50 行以外**的所有行 |

more 檔案

# 計算字數（wc）

```bash
wc [檔案]   # 印出行數、字數、字元數
```

> ==`wc` 允許標準輸入（鍵盤打字）當 input==
> 輸入資料後，同時按下 **Ctrl+D** 作為結束符號

| 選項 | 說明 |
|------|------|
| `-l` | 計算行數（line） |
| `-w` | 計算字數（word） |
| `-c` | 計算字元數（byte） |

---

# ==向 Bash Shell 送出結束訊號==

| 快捷鍵 | 說明 | 性質 |
|--------|------|------|
| `Ctrl+C` | 送出中斷信號給目前正在執行中的指令 | ==非正常終止== |
| `Ctrl+D` | 送出一個 EOF（End of File）字元，通常用來終止操控台的輸入 | ==正常的終止== |

# 進階處理工具 — 取代文字（tr）

可用來進行文字的替換或刪除。

| 選項 | 說明 |
|------|------|
| `-d` | 刪除訊息中的 SET1 字串 |
| `-s` | 取代重複的字元（連續重複只轉成 1 個） |

**範例：**

```bash
# 將所有小寫變成大寫
cat /etc/passwd | tr '[a-z]' '[A-Z]'

# 將冒號（:）刪除
cat /etc/passwd | tr -d ":"

# 將字元 'o' 取代成字元 '@'，遇到連續的 o 只會轉成 1 個 @
cat /etc/passwd | tr -s 'o' '@'
```

# 進階處理工具 — 排序（sort）

```bash
sort 檔案   # 將檔案中的資料排序並顯示結果
```

> 預設視為字串形態，比較字元的 ASCII 碼順序

| 選項        | 說明                          |
| --------- | --------------------------- |
| `-r`      | 反向（由大到小）排序                  |
| `-n`      | 以數值由小到大排序（例如 20 會排在 132 前面） |
| `-M`      | 以月份排序（例如 Aug、DEC 等）         |
| `-f`      | 忽略大小寫差異（A 與 a 視為相同）         |
| `-u`      | 排序並過濾重複的資料                  |
| `-t 分隔字元` | 指定排序時所用的欄位分隔字元              |
| `-k 數字`   | 以第幾個欄位來排序                   |

# 進階處理工具—過濾相鄰重複（uniq）

`uniq` 可將**相鄰重複**的文字整行刪除，留下不重複的資料。

> 未相鄰的行就無法處理，所以**一般會先進行排序再處理**

# 進階處理工具 — 剪取內容（cut）

`cut` 可將一行文字中，取出想要的部分。

**選項：**

| 選項 | 說明 |
|------|------|
| `-c 字元` | 依字元抓取 |
| `-f 數字N` | 取出第 N 筆欄位，左起由 1 起算 |
| `-d 分隔符號` | 分隔符號可用任何字元，預設是 TAB；若分隔符號為空白，可用單引號包起（例如 `-d ' '`） |

**指令範例：**

| 指令範例 | 說明 |
|----------|------|
| `ls -l \| cut -c 1-10` | 抓取第 1 至第 10 個字元 |
| `ls -l \| cut -d ' ' -f 3` | 以空白分隔，抓取第 3 欄 |
| `echo $PATH \| cut -d : -f 2` | 以 `:` 為分隔，抓取第 2 欄 |
| `cut -d : -f 5 /etc/passwd` | 抓取檔案第 5 欄 |
| `cut -d : -f 1,3 /etc/passwd` | 抓取檔案第 1 欄及第 3 欄 |
| `cut -d : -f 2-4 /etc/passwd` | 抓取檔案第 2、3、4 欄 |
