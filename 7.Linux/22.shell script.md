# Shell Script (指令稿)

Shell Script 是將多個指令寫在一個文字檔案內作為執行腳本，可用來達成**自動化**，節省重複輸入指令的時間。
- **命名慣例**：常被命名為 `*.sh` 以供識別。
- **執行原理**：
  - 是一種直譯式語言。
  - 程式碼由上到下、由左到右執行。
  - 空白行會被系統忽略。

---

## 1. Shebang 與註解

```bash
#!/bin/bash
# 這是一行註解
```

- **`#!/bin/bash`**：這行稱為 **shebang**，必須放置於 Script 的**第一行**，用來宣告該腳本要用 `/bin/bash` 程式來解譯。
- **註解**：其他以 `#` 開頭的行則表示為註解，執行時會被忽略。

> 💡 **換行符號問題**：
> 由於 Windows (`\r\n`) 跟 Linux (`\n`) 的換行符號不一致，強烈建議**在 Linux 平台上撰寫 Linux 腳本**，避免執行時發生莫名的格式錯誤。

---

## 2. 腳本的執行方式

執行腳本有四種常見方式，主要差異在於**是否開啟「子程序 (subshell)」**以及**是否讀取 shebang**。

| 指令 | 說明 | 變數影響範圍 | 備註 |
|------|------|-------------|------|
| `bash test.sh` | 啟動子 bash 執行 | **不會**影響父程序（原系統） | 忽略腳本內的 shebang |
| `./test.sh` | 視為執行檔執行 | **不會**影響父程序（原系統） | **需先 `chmod +x`**，會讀取 shebang |
| `source test.sh` | 直接在當前環境執行 | **會**影響父程序（原系統） | 忽略 shebang |
| `. test.sh` | 同 `source`，是縮寫寫法 | **會**影響父程序（原系統） | 忽略 shebang |

## 3. 指令稿中的特殊變數

| 變數 | 意義 |
|------|------|
| **`$0`** | 當前的腳本名稱（或指令的名稱） |
| **`$1`, `$2`...`$9`** | 分別代表執行腳本時傳進來的**第幾個參數** |
| **`$#`** | 傳入參數的**總個數** |
| **`$?`** | **上一個指令執行結果的「狀態碼」** |

**指令結束狀態碼 (`$?`)：**
- 執行指令後，系統會回傳一個狀態碼。
- **正常結束**：狀態碼為 `0`。
- **錯誤或異常**：狀態碼為「大於 0 的整數值」。

## 4. 變數宣告與陣列 (declare)

Shell 變數預設皆為**字串型態**，可使用 `declare` 宣告變數的特定類型：

| 選項 | 說明 | 範例 |
|------|------|------|
| `-i` | 宣告為**整數 (integer)** | `declare -i num1` |
| `-a` | 宣告為**陣列 (array)** | `declare -a car` |
| `-x` | 等同 `export`，設為**環境變數** | `declare -x PATH` |
| `-r` | 設為**唯讀 (read only)** | 不能更改內容，也不能 `unset` |

**整數運算 (`-i`)：**
- 預設只能處理到**整數**（無小數點），例如 `1/3` 的結果為 `0`。

**陣列設定 (`-a`)：**
```bash
declare -a car
car[1]="ford"
car[2]="benz"
echo ${car[1]}   # 輸出 ford
```

## 5. 條件判斷 (test 與 `[]`)

### A. 檔案類型及權限判斷
可利用 `test` 指令或放入 `[ ]` 中測試：

| 選項 | 說明 | 選項 | 說明 |
|------|------|------|------|
| **`-e`** | 檔案/目錄是否**存在** | **`-r`** | 是否**可讀** |
| **`-f`** | 是否為**一般檔案** | **`-w`** | 是否**可寫** |
| **`-d`** | 是否為**目錄** | **`-x`** | 是否**可執行** |
| **`-L`** | 是否為**連結檔** | | |

*範例：`test -f /tmp/file1` 或 `if [ -r /tmp/file1 ]; then`*

### B. 字串測試與比較
| 語法 | 說明 |
|------|------|
| `-n 字串` | 測試字串長度是否**大於 0** |
| `-z 字串` | 測試是否為**空字串** |
| `字串1 == 字串2` | 左右兩邊字串**相等** |
| `字串1 != 字串2` | 左右兩邊字串**不相等** |

> ⚠️ **注意**：`==` 與 `!=` 符號的**左右兩邊一定要有空白字元**！且變數與常數建議用**雙引號**包起來以防空白造成解析錯誤。

### C. 數值比較（需為整數）
| 符號 | 意義 | 記憶法 |
|------|------|--------|
| `-eq` | 等於 (=) | **eq**ual |
| `-ne` | 不等於 (!=) | **n**ot **e**qual |
| `-gt` | 大於 (>) | **g**reater **t**han |
| `-lt` | 小於 (<) | **l**ess **t**han |
| `-ge` | 大於等於 (>=) | **g**reater or **e**qual |
| `-le` | 小於等於 (<=) | **l**ess or **e**qual |

## 6. if 條件判斷式

> ⚠️ **重點提醒**：中括號 `[ ]` 的**內側兩端必須有空白字元**！

```bash
if [ 條件判斷式一 ]; then
    # 條件一成立時執行的工作
elif [ 條件判斷式二 ]; then
    # 條件二成立時執行的工作
else
    # 都不成立時執行的工作
fi
```

**範例一：測試輸入參數**
```bash
#!/bin/bash
if [ "$1" == "hello" ]; then
    echo "world"
elif [ "$1" == "" ]; then
    echo "Please input Parameter"
else
    echo "wrong parameter"
fi
```

**範例二：測試帳號是否存在**
```bash
#!/bin/bash
read -p "Input account to test: " account
isExist=$(id "$account" 2>/dev/null)  # 執行結果(stdout)存入 isExist，忽略 stderr

if [ "$isExist" == "" ]; then
    echo "not exist"
else
    echo "account exist"
fi
```

## 7. 命令執行的判斷依據 (`;`, `&&`, `||`)

| 符號 | 邏輯 | 說明 | 範例 |
|------|------|------|------|
| **`;`** | 循序執行 | 不論前一個是否成功，**一定會執行**下一個指令 | `cd /tmp ; rm *.txt` |
| **`&&`** | AND | 若指令1 **成功**（回傳 0），**才執行**指令2 | `ls file && echo "exist"` |
| **`||`** | OR | 若指令1 **失敗**（非 0），**才執行**指令2 | `ls file || echo "not exist"` |

> **綜合寫法範例**：
> `ls /tmp/myfile && echo "exist" || echo "not exist"`
> （檔案存在就印 exist，否則印 not exist）

## 8. case 流程控制

用於匹配特定字串模式，比起多重 `if-elif` 更為簡潔。

**語法結構與範例：**
```bash
#!/bin/bash
language='Java'

case $language in
    Java*) 
        echo "It is Java"
        ;;                   # ⚠️ 兩個分號表示該樣式段落結束
    Python*) 
        echo "It is Python"
        ;;
    C*) 
        echo "It is C"
        ;;
    *)                       # 相當於 else，前面都不符合時執行
        echo "None"
        ;;
esac
```

## 9. 迴圈控制

### A. for 迴圈
通常用於循序處理資料，或已知執行次數的場景。

```bash
# 寫法一：數值遞增 (起始式; 判斷式; 遞增式)
for ((i=0; i<10; i++))
do
    echo "$i"
done

# 寫法二：走訪清單
for var in Tom Mary John
do
    echo $var
done

# 寫法三：走訪指令執行結果
filelist=$(ls /tmp)
for name in $filelist
do
    echo "File name is ${name}"
done
```

### B. while 迴圈
當判斷式**成立時**進行迴圈，直到條件不成立才停止。
> 支援 `$((計算式))` 進行 `+, -, *, /, %` 數值運算。

```bash
i=0
while [ $i != 10 ]
do
    echo $i
    i=$(($i+1))   # 讓 i 每次都增加 1
done
```

**利用 while 讀取檔案的一行一行：**
```bash
while read input
do
    echo $input
done < /etc/passwd    # 使用資料流導入符號，將檔案餵給 read
```

### C. until 迴圈
當判斷式**成立時就終止**迴圈，否則持續進行。

```bash
i=0
until [ $i -ge 10 ]   # 直到 i 大於等於 10 就停止
do
    echo $i
    i=$(($i+1))
done
```

## 10. 函式 (Function)

可將重複的程式碼打包，呼叫時可帶入參數（在函式內部同樣使用 `$1`, `$2` 讀取參數，但它們代表的是**傳給函式的參數**，而不是腳本的參數）。

```bash
#!/bin/bash

# function 關鍵字為選擇性，也可直接寫 myFun()
function myFun() {
    # ${0} 是指令名稱，${1} 是呼叫函式時帶入的第一個參數
    echo "${0} hello ${1}"
}

# 呼叫函式並帶入參數 "world"
myFun "world"
```
