# Bash 變數（Variables）

變數是以一個「固定字串」來代表「不固定的內容」。在 Linux 中，變數分為**一般變數**與**環境變數**。

### 命名規則與慣例
- 只能使用**英文字母、數字與底線**。
- **第一個字元不能是數字**。
- 慣例上：
  - **自訂一般變數**：用**小寫**字母。
  - **系統環境變數**：用**大寫**字母。

---

## 1. 變數生效範圍（一般 vs 環境）

| 變數類型 | 生效範圍 | 設定方式 | 說明 |
|----------|----------|----------|------|
| **一般變數** | **當前 Shell** | `var=value` | 只有自己這個終端機視窗認得，開啟子 bash 或執行腳本時就會失效。 |
| **環境變數** | **當前 Shell ＋ 所有子 Shell** | `export var=value` | 常用來記錄登入資訊，子行程會繼承該變數。 |

### `export` 設定與語法

`export` 指令的作用是將「一般變數」升級成「環境變數」，讓後續衍生的子行程也能讀取到該變數。

```bash
# 寫法一：先宣告一般變數，再升級
MY_VAR="hello"
export MY_VAR

# 寫法二：宣告的同時直接升級（最常見）
export MY_VAR="hello"

# 檢視目前系統中所有的環境變數
export -p
```

### 實驗範例：父子 Shell 繼承關係

> 💡 **核心觀念**：環境變數的傳遞是**單向的（上游往下游）**。
> 父行程的環境變數會複製給子行程，但子行程對變數的修改與刪除，**絕對不會影響到父行程**。

```bash
foo=test          # 1. 設為一般變數
echo $foo         # 輸出：test
bash              # 2. 進入子 bash
echo $foo         # 輸出：（空白，一般變數無法繼承）
exit              # 3. 回到父 bash

export foo        # 4. 將 foo 升級成「環境變數」
bash              # 5. 再次進入子 bash
echo $foo         # 輸出：test（成功繼承！）

foo=new_value     # 6. 在子 bash 中修改變數
unset foo         #    或是直接刪除變數
exit              # 7. 結束子 bash，回到父 bash

echo $foo         # 輸出：test（父 bash 的變數原封不動，不受影響！）
```

## 2. 檢視與取得變數值

| 動作 | 指令 | 說明 |
|------|------|------|
| **檢視所有環境變數** | `export` 或 `env` | 列出目前系統中所有的環境變數與值 |
| **印出單一變數** | `echo $變數名稱` | 印出該變數的值（若變數不存在，則印出空白，不會報錯） |
| **嚴謹寫法** | `echo ${變數名稱}` | 避免變數名稱與後面字串混淆時使用 |

## 3. 設定與移除變數

```bash
var=value      # 設定變數 = 變數值
unset var      # 移除變數
```

### ⚠️ 設定變數的注意事項
1. 變數預設視為**字串形式**。
2. 等號 `=` 兩邊**絕對不能接空白字元**。
3. 變數值若包含空白字元，必須使用**引號**標註範圍。

### 設定範例與邏輯
```bash
A=100        # 將變數 A 設定為字串 "100"
B=A          # 將變數 B 設定為字串 "A"（沒有 $，所以只是純文字）
C=$A         # 將變數 C 設定為「變數 A 的值」

echo $A      # 輸出：100
echo $B      # 輸出：A
echo $C      # 輸出：100
```

## 4. 處理字串：空白、引號與跳脫字元

當變數值內有空白，或者特殊符號時，需要特別處理：

| 符號 | 特性 | 範例 | 說明 |
|------|------|------|------|
| **雙引號 `" "`** | **保留變數特性** | `echo "$var"` | 雙引號內的 `$變數` 會被解析成變數值。如果要保留字串內的連續空白，丟給 `echo` 時也需加雙引號。 |
| **單引號 `' '`** | **純文字** | `echo '$var'` | 單引號會使 `$變數` **失效**，直接印出 `$var` 字串。 |
| **跳脫字元 `\`** | **剝奪特殊意義** | `A=Tom\'s\ pen` | 將符號（如單引號、空白）變回普通字元。 |

**練習：設定變數值為 `Tom's pen`**
```bash
# 錯誤寫法（有空白、有單引號會報錯）
A=Tom's pen

# 正確寫法一：用雙引號包住
A="Tom's pen"

# 正確寫法二：用跳脫字元
A=Tom\'s\ pen
```

## 5. 變數的實用操作

### 增加路徑捷徑
利用變數可以提高操作方便性，例如設定長路徑的捷徑：
```bash
work=/tmp/myproject/backend/src
cd $work      # 瞬間切換過去
```

### 擴充原有變數（Append）
若想在原有變數值後方**新增字串**，可先用 `$` 取回原值，再接上新字串：
```bash
# 情境：將 /tmp/bin 加入環境變數 PATH 中
PATH=$PATH:/tmp/bin               # 成功新增

# 情境：為 Name 加上 newword
Name="$Name"newword               # 成功新增
Name=${Name}newword               # 成功新增（推薦寫法）
Name=$Namenewword                 # ❌ 失敗：系統會以為你在找一個叫 $Namenewword 的變數
```

---

### 擷取指令輸出結果（Command Substitution）

這是腳本中最常用的技巧之一！可以將某個**指令的執行結果**，直接存入變數中。

```bash
# 語法：$(指令) 或是使用反引號 `指令`
TODAY=$(date +%Y-%m-%d)
echo "今天是 $TODAY"

# 結合管線指令計算檔案數量
FILE_COUNT=$(ls -1 | wc -l)
echo "目前目錄有 $FILE_COUNT 個檔案"
```

### 變數的預設值與長度（參數擴展）

| 用法 | 語法 | 範例與說明 |
|------|------|------------|
| **設定預設值** | `${變數:-預設值}` | `MSG=${1:-"Hello"}`<br>若沒有傳入 `$1` 或為空，則 `MSG` 就等於 `"Hello"` |
| **計算長度** | `${#變數}` | `STR="Linux"`<br>`echo ${#STR}` 會輸出 `5` |
| **字串替換** | `${變數/舊字/新字}` | `PATH=${PATH/bin/BIN}`<br>將變數內容中的第一個 `bin` 替換為 `BIN` |

## 6. 讀取使用者輸入（read）

可以使用 `read` 指令讀取來自鍵盤的輸入，並存成變數：

```bash
# -p 參數用來印出提示字串
read -p "請輸入您的名字: " name
echo "你好, $name"
```

## 7. 常見的系統環境變數

這些變數系統會自動維護，慣例皆為大寫：

| 變數 | 說明 |
|------|------|
| **`HOME`** | 使用者家目錄的絕對路徑 |
| **`PATH`** | 執行檔搜尋路徑（各路徑用 `:` 隔開） |
| **`PWD`** | 記錄使用者目前所在的目錄 |
| **`UID`** | 目前的使用者 uid |
| **`USER` / `LOGNAME`** | 使用者的登入名稱 |
| **`SHELL`** | 目前使用哪個 shell 介面（如 `/bin/bash`） |
| **`HISTFILE`** | 指令歷史紀錄的檔案存放位置 |
| **`LS_COLORS`** | 設定 `ls` 顯示的 Shell 顏色 |
