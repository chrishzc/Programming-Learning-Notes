# 簡介
檔案系統是一種用來存取目錄或檔案資料的機制，不同類型對檔案大小會有不同的限制
- 常用類型：
  - 微軟作業系統常用 NTFS
  - 隨身碟常為 Fat32
  - Ubuntu 使用 ext4
- 檔案系統類型將影響：
  - 檔案路徑存取方式
  - 效能與穩定性
  - 容量上限
  - 容錯能力

# Linux 檔案系統結構
- 為單一樹狀結構
- 最頂層為根目錄（以 `/` 表示），所有檔案或目錄皆是由根目錄往下延伸

## FHS (FileSystem Hierarchy Standard)
定義了 Linux 作業系統中的主要目錄及目錄內容
- ==只定義根目錄及下一層目錄的內容（最上面兩層）==
- 更下層目錄則由各 Linux 發行版本自行定義

# 帳號與家目錄
每個使用者帳號會擁有自己私人的目錄空間（家目錄）
- 只有該帳號及系統管理者（root）才有存取該目錄的權限
- 家目錄名稱預設與使用者帳號相同
- 一般使用者的家目錄為 `/home/帳號/`，例如 `/home/user1/`
- root 帳號的家目錄則為 `/root/`
- ==桌面環境下的「Home 資料夾」≠「home」==

## 家目錄的作用
當使用者啟動 bash 時，系統預設會切換至家目錄
- 波浪符號（`~`）用來代表該帳號的家目錄，以供方便使用
- 例如若要切換至家目錄，可執行指令 `cd ~`

# 系統重要目錄

| 目錄       | 說明                                                                  |
| -------- | ------------------------------------------------------------------- |
| `/`      | 根目錄                                                                 |
| `/home/` | ==各個帳號家目錄的集中地==                                                     |
| `/root/` | root 帳號的家目錄                                                         |
| `/bin/`  | 存放系統中最常用的基本使用者指令                                                    |
| `/sbin/` | 僅供系統管理者執行的指令                                                        |
| `/lib/`  | 存放基本的共用函式庫檔案及核心模組驅動                                                 |
| `/usr/`  | 全文為 Unix Software Resource，==目錄內包含系統的主要程序、圖形介面所需的檔案、自行安裝的軟體、系統文件等== |
| `/tmp/`  | ==存放暫存檔案，所有使用者對該目錄都具有讀寫權限==                                         |
| `/dev/`  | 所有裝置與設備，包括鍵盤滑鼠、硬碟、USB 等，皆以檔案或目錄方式存在於此目錄中，以便於系統管理                    |
| `/etc/`  | ==存放系統的設定檔案，例如使用者帳戶資訊、主機名稱等==                                       |
| `/var/`  | ==存放長度可變的檔案，例如伺服器的記錄檔案（log）==                                       |
| `/sys/`  | 內含檔案用來檢視及設定系統硬體資訊                                                   |
| `/mnt/`  | 光碟或其他媒體預設掛載點（mount point）的地方                                        |
| `/opt/`  | ==作為 optional 檔案和程式的存放目錄，例如非預設安裝的外來軟體常會安裝於此==                       |
==/tmp/:每個使用者都可以新增檔案進去，但只有該檔案上傳者、ROOT可以刪除該檔案。==

# 路徑
- 指令、路徑、檔案及目錄名稱一律**區分大小寫**
- 以 `/` 間隔上層目錄與下層目錄
- Linux 檔案常不使用附檔名，尤其是執行檔
- 系統會利用屬性（metadata）來記錄檔案類型、權限、修改時間及檔案大小等，而非依賴副檔名
- 目錄路徑的尾端可加上 `/` 以輔助辨識

## 絕對路徑 vs. 相對路徑

|      | 絕對路徑                                                                 | 相對路徑                                                     |
| ---- | -------------------------------------------------------------------- | -------------------------------------------------------- |
| 起點   | 由根目錄 `/` 開始                                                          | 以當前目錄為起點                                                 |
| 特徵   | 一定由 `/` 寫起                                                           | 一定**不**由 `/` 寫起                                          |
| 特殊符號 | `~` 代表家目錄                                                            | `./` 當前目錄、`../` 上一層目錄                                    |
| 範例   | `/`<br>`/tmp/<br>/home/user1/`<br>`/home/user1/f1.txt`<br>`~/f1.txt` | `./test/`<br>`file1.txt`<br>../ <br>../../tmp/file2.txt` |
