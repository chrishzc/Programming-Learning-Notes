# 在檔案內搜尋字串（grep）

```bash
grep [選項]... "比對字串" [檔案]...   # 預設顯示字串所在整行
```

## 常用選項

| 選項                             | 說明                    |
| ------------------------------ | --------------------- |
| `-o`                           | ==只印出相符的字串==          |
| `-n`                           | ==印出字串所在的行號==         |
| `-H`                           | 印出字串所在的檔名             |
| `-v`                           | 反向選擇（顯示不符合的行）         |
| `-i` / `--ignore-case`         | 不區分大小寫                |
| `-l` / `--files-with-matches`  | 列出內容符合的檔案名稱           |
| `-L` / `--files-without-match` | 列出內容不符合的檔案名稱          |
| `-w`                           | ==須全字相符==             |
| `-c` / `--count`               | 印出具相符結果的總行數           |
| `-s` / `--no-messages`         | 不顯示錯誤資訊(2>)           |
| `-m N`                         | 只列出前 N 個符合結果          |
| `-A 行數`                        | 找到字串後，也顯示其後（after）幾行  |
| `-B 行數`                        | 找到字串後，也顯示其前（before）幾行 |

## 指令範例

| 指令範例                            | 說明                                   |
| ------------------------------- | ------------------------------------ |
| `grep -n -w "home" /etc/passwd` | 顯示 `/etc/passwd` 內出現 `home` 的地方（含行號） |
| `grep -o "home" /etc/passwd`    | 只印出 `"home"`，不印出其他字元                 |
| `grep -c "home" /etc/passwd`    | 顯示含有 `home` 字串的行數                    |
| `grep -Hn "home" /etc/*`        | 找出 `/etc/` 目錄下含有 `home` 的所有檔案        |
| `history \| grep "ls"`          | ==列出指令記錄內出現 `ls` 字串的紀錄==             |

# 正規表達式（Regular Expression）

> 也稱為正規表式法、regex、regexp==只支援搜索文字==

- 使用特定符號來定義文字的樣式（如身分證字號）
- 可用來取代規律、重複的繁瑣動作
- 限制：必須是**純文字格式**
- 比對方式為**從左至右**
- 搜尋時建議用單引號或雙引號標注起來
- 正規表達式有延伸版本（Extended Regex）：
  - `grep` 只支援早期版本；若要使用完整正規表達式，請用 `grep -E` 或 `egrep`

## 正規表示法 vs 萬用字元

| 特性         | 正規表示法（regex）              | 萬用字元（wildcard）          |
| ---------- | ------------------------- | ----------------------- |
| **使用時機**   | 搜尋**檔案內容**（`egrep`、`sed`） | 搜尋**檔案名稱**（`ls`、`find`） |
| 比對目標       | ()                        | {}                      |
| 任意長度       | `.*`                      | `*`                     |
| 任意單一字元     | `.`                       | `?`                     |
| 指定字元       | `[ ]`                     | `[ ]`                   |
| 範圍         | `[ - ]`                   | `[ - ]`                 |
| 黑名單        | `[^ ]`                    | `[^ ]`                  |
| 列舉         | (a\|b)                    | `{ a , b }`             |
| 計次：0 或 1   | `?`                       | —                       |
| 計次：0 以上    | `*`                       | —                       |
| 計次：1 以上    | `+`                       | —                       |
| 計次：n 次     | `{n}`                     | —                       |
| 計次：n ~ m 次 | `{n,m}`                   | —                       |
| 行首         | `^`                       | —                       |
| 行尾         | `$`                       | —                       |
| 字首         | `\<`                      | —                       |
| 字尾         | `\>`                      | —                       |


> `grep` 常搭配管線使用，例如：`history | egrep -w "(find|ls)"`

# 比對「一個字元」的符號

| 符號 | 意義 | 範例 |
|------|------|------|
| `.` | 任意一個字元（不可為空字元） | `r.t` 可符合 `rat`、`r2t`、`r@t`，但不符合 `rt`；`c..y` 可符合 `copy`、`ca2y` |
| `[ ]` | 中括號中任一字元 | `[abz]` 表示 `a`、`b`、`z` 其中一個；`[!>]` 表示 `!` 或 `>` |
| `[ - ]` | 一組連續範圍 | `[A-Za-z]` 表示一個英文字元；`[0-9]` 表示一個數字；`[0-25]` 表示可為 0、1、2、5 |
| `[^ ]` | 排除中括號內的任何一個字元 | `[^13]` 表示不能是 `1` 或 `3`；`[^0-9]` 表示不可為數字 |

# 輔助符號（計次）

> 用來表達前面的「樣板」重複出現的次數；樣板可能是一個字元，或由小括號括起來的一長串

| 符號 | 意義 | 範例 |
|------|------|------|
| `?` | 樣板出現 0 次或 1 次 | `ra?t` 可符合 `rt` 或 `rat` |
| `*` | 樣板出現 0 次以上 | `ra*t` 可符合 `rt`、`rat`、`raat` |
| `+` | 樣板重複出現 1 次以上 | `r.+t` 可符合 `rat`、`rent`、`r@t`，但不能 `rt` |
| `{n}` | 樣板重複出現 n 次 | `ba(na){2}` 符合 `banana` |
| `{n,m}` | 樣板重複出現 n 到 m 次 | `go{1,3}gle` 符合 `gogle`、`google`、`gooogle` |

> ==貪婪原則：預設從相符的字串中，挑選**最長的**當作最終結果==

# 位置符號

| 符號    | 意義       | 範例                                                                                 |
| ----- | -------- | ---------------------------------------------------------------------------------- |
| `( )` | 界定分組匹配範圍 | `([0-9])-([0-9])` 例如 `1-2`；`(YES\|NO)` 表示 YES 或 NO；`g(la\|oo)d` 符合 `glad` 或 `good` |
| `^`   | 樣板出現在行首  | `^(They)`                                                                          |
| `$`   | 樣板出現在行尾  | `(mp3)$`                                                                           |
| `\<`  | 樣板出現在字首  | `\<(goo)`                                                                          |
| `\>`  | 樣板出現在字尾  | `(gle)\>`                                                                          |
|       |          |                                                                                    |

# 對數字的處理

> 正規表達式**一律以字串**來看待比對項目
> `[0-255]` **不會**比對 0~255 的數字，而是被視為 `0-2`、`5`、`5`，等同於 `[0125]`

| 目的       | 範例                                                                              |
| -------- | ------------------------------------------------------------------------------- |
| 找出數字     | `egrep '[0-9]' /etc/passwd` 或 `egrep '[[:digit:]]' /etc/passwd`                 |
| 找出 0~9   | `egrep -w '[0-9]' /etc/passwd`                                                  |
| 找出 0~99  | `egrep -w '([0-9]\|[1-9][0-9])' /etc/passwd`                                    |
| 找出 0~255 | `egrep -w '([0-9]\|[1-9][0-9]\|1[0-9][0-9]\|2[0-4][0-9]\|25[0-5])' /etc/passwd` |

# 跳脫符號（`\`）

讓後面的字元失去特殊功用，轉為純字元。

- 後面可使用：`` ^ . [ $ ( ) | * + ? { \ `` 等字元
- `[ ]` 內**不需要**使用跳脫字元

```bash
\.   # 表示 . 這個字元
\\   # 表示 \ 這個字元

grep -E '[a-z.-]' ~/.bashrc   # 找出小寫字母以及 . 和 -（[] 內不需跳脫）
```

# 意義字符（Linux 專屬）

| 符號             | 意義          | 效用（等同）               |
| -------------- | ----------- | -------------------- |
| `[[:alnum:]]`  | 所有英文字大小寫和數字 | `[A-Za-z0-9]`        |
| `[[:alpha:]]`  | 所有英文字大小寫    | `[A-Za-z]`           |
| `[[:digit:]]`  | 所有數字        | `[0-9]`              |
| `[[:xdigit:]]` | 16 進位的數字類型  | `[0-9A-Fa-f]`        |
| `[[:lower:]]`  | 所有英文字小寫     | `[a-z]`              |
| `[[:upper:]]`  | 所有英文字大寫     | `[A-Z]`              |
| `[[:punct:]]`  | 所有標點符號      | `[：" ' ? ! ; : # $]` |
| `[[:blank:]]`  | 空白          | 空白鍵及 Tab 鍵           |
| `[[:space:]]`  | 空白（含換行）     | 空白鍵、Tab 鍵及 CR        |
| `[[:cntrl:]]`  | 控制按鍵        | CR、LF、Tab、Del 等      |

# Linux 支援的特殊序列符號

| 符號 | 意義 | 效用（等同） |
|------|------|------------|
| `\w` | 數字、字母、底線 | `[A-Za-z0-9_]` |
| `\W` | `\w` 的反向 | `[^A-Za-z0-9_]` |

> **備註**：各系統（語言）對 Regex 的支援度不同。例如在 Python 可用 `\d` 代表數字，但 Linux `grep` 不支援。
