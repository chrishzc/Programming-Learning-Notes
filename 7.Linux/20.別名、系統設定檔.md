# 指令別名（alias / unalias）

「別名」可用來將冗長或常用的指令，設定成一個**方便記憶的短字串**。

### 常用語法與範例

| 動作 | 語法 | 說明 |
|------|------|------|
| **設定別名** | `alias 別名="指令內容"` | 設定新的別名取代長指令 |
| **移除別名** | `unalias 別名` | 刪除已設定的別名 |
| **查看所有** | `alias` | 列出目前系統中所有生效的別名 |

**執行範例：**
```bash
alias cl="clear"             # 設定 cl 等同於 clear
alias temp="cd /tmp; ls"     # 設定 temp 等同於執行 cd /tmp 再執行 ls
unalias cl                   # 刪除 cl 這個別名
```

**系統預設常見的別名（輸入 `alias` 可見）：**
```bash
alias egrep='egrep --color=auto'
alias grep='grep --color=auto'
alias ll='ls -alF'
alias ls='ls --color=auto'
```

# 指令運作原理與環境變數

當使用者在終端機輸入一串指令時，系統會依照以下順序來判斷該如何執行：

```mermaid
flowchart TD
    A["使用者輸入指令 (例如 ls)"] --> B{"是否有指定\n絕對/相對路徑？"}
    B -->|是 (如 /bin/ls)| C["直接執行該路徑的檔案"]
    B -->|否| D{"是否為設定的 Alias？"}
    D -->|是| E["執行 Alias 對應的指令"]
    D -->|否| F{"是否為 Bash 內建指令？\n(如 cd, echo)"}
    F -->|是| G["執行內建指令"]
    F -->|否| H{"去環境變數 $PATH\n尋找是否有同名執行檔？"}
    H -->|找到| I["執行該檔案"]
    H -->|找不到| J["報錯：找不到指令\n(Command not found)"]
```

### 認識 `$PATH` 環境變數

`PATH` 是一個用來**記錄系統執行檔（指令）所在目錄清單**的變數。
- 當我們輸入指令（如 `ls`）而沒有給絕對路徑時，系統就會去 `$PATH` 記錄的目錄裡面尋找。
- 各個目錄路徑以冒號 `:` 區隔。
- 系統會**依序**在各目錄內搜尋，一旦找到符合名稱的執行檔就會**停止搜尋並執行**。

**查看 PATH 的內容：**
```bash
echo $PATH
# 輸出範例：/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

# 系統重要的設定檔

於命令列（終端機）直接設定的變數或是別名，**無法「長久維持」**，重開機或者切換終端機後就會復原。
因此，若要永久保存設定，必須將指令寫入「系統設定檔」。

> 系統在重啟或是帳號登入時，會自動重新讀取這些設定檔的內容。

| 設定檔路徑 | 影響範圍 | 修改權限 | 說明 |
|-----------|----------|----------|------|
| `~/.bashrc` | **單一使用者**（只限自己） | 該使用者即可 | 每個帳號家目錄內都有一份，可自行修改 |
| `/etc/profile` | **全域**（所有帳號） | 需 **root** 權限 | 影響整個系統及所有使用者帳號 |

# 於設定檔內「永久」設定別名

若希望每次開啟終端機都能使用自訂的別名，可以將 `alias` 指令寫入 `~/.bashrc`：

1. **編輯設定檔**：
   ```bash
   nano ~/.bashrc    # 或是用 gedit、vim 編輯
   ```
   > 進入檔案後，將 `alias 你的別名="指令"` 加到檔案的最下方，存檔離開。

2. **重新套用設定檔（使之立刻生效）**：
   ```bash
   source ~/.bashrc
   ```

# source 指令

`source` 指令用來**立即套用系統設定檔**或是執行腳本內容。

例如，剛修改完 `~/.bashrc` 檔案後，修改的內容並不會自動生效。要讓它生效有兩種方法：
1. **重新開機**或者將**帳號登出再重新登入**（系統會自動讀取）。
2. **手動指定套用設定檔**（推薦做法，省時方便）：
   ```bash
   source ~/.bashrc
   ```
