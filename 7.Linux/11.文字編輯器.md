# 文字編輯器介紹

| 類型 | 工具 |
|------|------|
| 圖形介面 | `gnome-text-editor` |

# gnome-text-editor

- GNU 出品的圖形文字編輯器
- 可下指令或在圖形介面中開啟
- **純文字介面下無法使用**

# nano

| 快捷鍵 | 功能 |
|--------|------|
| `Alt + 6` | 複製一整行 |
| `Ctrl + K` | 剪下一整行 |
| `Ctrl + U` | 貼上 |
| `Ctrl + W` | 搜尋（輸入關鍵字後按 Enter；按 `Alt+W` 跳到下一筆） |
| `Ctrl + Y` | 翻到上一頁 |
| `Ctrl + V` | 翻到下一頁 |
| `Ctrl + O` | 保存 |
| `Ctrl + X` | 退出 |

## 操作模式

![[{3053F61D-B1C6-406E-8A19-6EC79E22AB4F}.png|637]]

Vim 有三種模式，隨時可按 `Esc` 回到**一般模式**。

### 啟動 / 進入一般模式

```bash
vim test.txt   # 開啟檔案（預設進入一般模式，無法輸入文字）
```

### ==一般模式 → 編輯模式==

| 按鍵 | 全名 | 說明 |
|------|------|------|
| `a` | append | 從游標**後一個字元**開始輸入 |
| `i` | insert | 從游標**當前位置**插入輸入 |
| `o` | open | 在游標**下方新增一行**，並移到行首 |

### ==一般模式 → 指令列模式（先按 Esc，再按 `:`）==

| 指令           | 說明           |
| ------------ | ------------ |
| `:h`         | help         |
| `:w`         | 存檔           |
| `:w 檔名`      | 另存新檔         |
| `:wq` 或 `zz` | 存檔並離開        |
| `:q!`        | 強制離開（不存檔）    |
| `:5,9w 檔名`   | 將第 5~9 行存到檔案 |

## 游標移動（一般模式）

### 基本移動

| 按鍵 | 說明 |
|------|------|
| `h` / `←` | 左 |
| `j` / `↓` | 下 |
| `k` / `↑` | 上 |
| `l` / `→` | 右 |
| `0` | 移動到此行的開頭 |
| `$` | 移動到此行的結尾 |
| `5G` 或 `:5` | 移動到第 5 行 |
| `1G` | 移動到第一行 |
| `G` | 移動到最後一行 |

### 進階移動

| 按鍵   | 說明                        |
| ---- | ------------------------- |
| `w`  | 移到下一個 word                |
| `b`  | 移動至上一個 word               |
| `(`  | 移動至上一句                    |
| `)`  | 移動至下一句                    |
| `{`  | 移至該段落之首                   |
| `}`  | 移至該段落之末                   |
| `%`  | 移動至相對應的 `()`、`{}`、`[]` 符號 |
| `H`  | 移動至現在螢幕畫面的開頭              |
| `M`  | 移動至現在螢幕畫面的中間              |
| `L`  | 移動至現在螢幕畫面的結尾              |
| :+數字 | 移動到該數字的行數                 |

## ==刪除、複製、貼上（一般模式）==

### 刪除（delete）

| 按鍵 | 說明 |
|------|------|
| `x` | 刪除游標所在位置的字元（如同 Delete） |
| `X` | 倒退刪除（如同 Backspace） |
| `dl` | 刪除一個字元 |
| `dw` | 從游標位置刪除到下一個單字 |
| `D` | 從游標位置刪除到行末 |
| `dd` | 刪除游標所在的整行 |
| `5dd` | 刪除游標開始的 5 行 |
| `:6,9d` | 刪除第 6~9 行（指令列模式） |

### 複製（yank）

| 按鍵 | 說明 |
|------|------|
| `yy` | 複製游標所在的整行 |
| `3yy` | 複製從游標開始的 3 行 |
| `yw` | 複製目前單字 |
| `yG` | 複製當前行到最後一行 |
| `y0` | 複製到行首（不含游標所在字元） |
| `y$` | 複製到行尾（含游標所在字元） |
| `y7G` | 複製到第 7 行 |

### 貼上（put）

| 按鍵 | 說明 |
|------|------|
| `p` | 將複製（或刪除）的內容插入到游標**後面** |
| `P` | 將複製（或刪除）的內容插入到游標**前面** |

## 搜尋及其他（一般模式）

| 按鍵       | 說明                |
| -------- | ----------------- |
| `/字串`    | 往後搜尋字串            |
| `?字串`    | 往前搜尋字串            |
| `n`      | 找下一筆              |
| `N`      | 找上一筆              |
| `:noh`   | 取消搜尋高亮（指令列模式）     |
| `J`      | 將目前行與下面的行合併為一行    |
| `u`      | ==Undo（復原最後的修改）== |
| `Ctrl+R` | ==Redo==          |
| `.`      | 重複上次的動作           |

## 環境設定（指令列模式）
==只會一次性套用，重開後不會繼續套用==

| 指令 | 說明 |
|------|------|
| `:set number` 或 `:set nu` | 顯示行號 |
| `:set nonumber` 或 `:set nonu` | 取消行號 |
| `:set ai` | 自動內縮（auto-indent） |
| `:set noai` | 取消自動內縮 |
| `:set ignorecase` | 搜尋不分大小寫 |
| `:set noignorecase` | 搜尋區分大小寫 |
| `:set tabstop=4` | Tab 設定為 4 個空白 |
| `:set shiftwidth=4` | 內縮設定為 4 個空白 |

## 設定檔 `~/.vimrc`

使用者可編輯家目錄下的 vim 設定檔，讓設定永久生效：

```bash
vim ~/.vimrc
```

| 設定字串 | 說明 |
|---------|------|
| `set number` | 顯示列號 |
| `syntax on` | 語法高亮度顯示 |
| `set hlsearch` | 標記搜尋到的字串 |
| `set autoindent` | 自動縮排 |
| `set ruler` | 顯示說明 |
| `set showmode` | 顯示編輯狀態 |
| `set tabstop=4` | 設定 Tab 鍵的字元數 |
| `set enc=utf8` | 文字編碼加入 utf8 |
| `set ignorecase` | 搜尋不分大小寫 |
| `set background=dark` | 設定顯示的亮度 |
