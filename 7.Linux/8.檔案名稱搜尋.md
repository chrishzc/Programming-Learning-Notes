# 系統如何尋找執行檔

Linux 利用環境變數 `PATH` 來記錄指令的所在目錄清單：
- 由多個目錄組成，以 `:` 區隔
- 執行 `echo $PATH` 可以檢視內容
- 依序在各目錄內搜尋可執行檔（指令），一旦找到後就不再繼續找

---

# 顯示==指令==位置（which / whereis）

| 指令 | 說明 | 範例 |
|------|------|------|
| `which <指令>` | 顯示指令的位置，**只在 `$PATH` 內搜尋** | `which cp` → `/usr/bin/cp` |
| `whereis <指令>` | 搜尋二進位檔案、原始碼或說明文件 | `whereis cp` |

---

# Shell 萬用字元（Wildcard）

> 也可執行 `man 7 glob` 查詢用法==只支援搜索檔名==

| 字元 | 功能 | 範例 |
|------|------|------|
| `*` | 比對 0 個以上任意字元 | `c*` 表示以 `c` 開頭的所有檔案/目錄 |
| `?` | 比對恰有一個任意字元 | `c??` 表示以 `c` 開頭、名稱長度為 3 個字元 |
| `[ ]` | 比對一個括號內指定的字元 | `file[159]` 表示 `file1` 或 `file5` 或 `file9` |
| `[ - ]` | 比對在編碼順序範圍內的一個字元 | `[0-9]` 表示 0 至 9 之間任一字元；`[b-d]*` 表示開頭為 b 或 c 或 d 的所有檔案/目錄 |
| `[^ ]` | 反向選擇（黑名單） | `[^abc]` 代表非 a、b、c 的其他任一字元 |
| `{ , }` | 以逗號為間隔進行列舉 | `cp {*.txt,*.pdf} /tmp` 表示將 pdf 及 txt 複製到 `/tmp` |
| `{..}` | 數字或字母範圍展開 | `touch {1..200}.txt` 表示產生 `1.txt` ~ `200.txt` |

## 範例

| 指令範例 | 說明 |
|----------|------|
| `ls /bin/h*t` | 列出 `/bin/` 內 `h` 開頭、`t` 結尾的檔案或目錄 |
| `ls /bin/y*` | 列出 `/bin/` 內 `y` 開頭的檔案或目錄 |
| `ls /bin/*[0-9]*` | 列出 `/bin/` 內名稱包含數字的檔案或目錄 |
| `ls /bin/[^a-x]??` | 列出 `/bin/` 內非 `a` 至 `x` 開頭、名稱為 3 個字元的檔案或目錄 |
| `ls *.txt` | 列出當前目錄下附檔名為 `txt` 的檔案 |

# 顯示指令/檔案類型（type / file）

## type

==顯示指令==的類型（執行檔、別名、內建指令等）。

```bash
type cp    # cp is /usr/bin/cp
type ll    # ll is aliased to 'ls -l --color=auto'
type cd    # cd is a shell builtin
```

## file

顯示==檔案或目錄==的類型（文字檔、目錄、執行檔等）。

```bash
file /etc/passwd   # 文字檔
file /bin/         # 目錄
file /bin/cp       # 執行檔
```

# 尋找==檔案==位置（find）

```bash
find [搜尋路徑]... [選項]...
```

- 翻硬碟搜尋檔案，速度較慢
- 搜尋路徑可為多個目錄，以空白分隔
- 若無指定路徑，預設搜尋當前目錄（及子目錄）

## 常用選項

| 類別      | 選項               | 說明                                               |
| ------- | ---------------- | ------------------------------------------------ |
| **名稱**  | `-name 檔名`       | ==檔名若使用萬用字元，須加引號==                               |
| **類型**  | `-type f`        | 搜尋檔案                                             |
| **類型**  | `-type d`        | 搜尋目錄                                             |
| **使用者** | `-user 帳號`       | 指定擁有者帳號（也可用 `-uid`）                              |
| **群組**  | `-group 群組`      | 指定群組（也可用 `-gid`）                                 |
| **大小**  | `-size [+-]SIZE` | `c`=byte、`k`=KB、`M`=MB、`G`=GB；`-empty` 搜尋空的檔案或目錄 |
| **時間**  | `-mtime 4`       | 4 天前當天被更動過                                       |
| **時間**  | `-mtime +4`      | 4 天前（不含第 4 天）以前被更動過                              |
| **時間**  | `-mtime -4`      | 4 天以內被更動過                                        |
| **時間**  | `-newer file1`   | 比 `file1` 還要新的                                   |
| **深度**  | `-maxdepth N`    | 最深不超過 N 層（建議放在最前面）                               |

==不只可以帶多個參數，它還能透過邏輯運算子（AND、OR、NOT）把各種條件拼在一起==
## find 範例

| 指令範例                                  | 說明                              |
| ------------------------------------- | ------------------------------- |
| `find /lib/ -name "java"`             | 找出 `/lib/`（及子目錄）內的 `java`       |
| `find /boot/ /usr/ -name "*.img"`     | 列出 `/boot/` 及 `/usr/` 內的 img 檔案 |
| `find /bin/ -name "??"`               | 列出 `/bin/` 內名稱為 2 個字元的檔案或目錄     |
| `find /boot/ -type d`                 | 列出 `/boot/` 內所有目錄               |
| `find /boot/ -user root -type f`      | 列出 `/boot/` 內屬於 root 的檔案        |
| `find /bin/ -size +500k`              | 列出 `/bin/` 內大於 500 KB 的檔案或目錄    |
| `find /bin/ -size -5c`                | 列出 `/bin/` 內小於 5 byte 的檔案或目錄    |
| `find /boot/ -type f -size +2M`       | 列出 `/boot/` 內大於 2 MB 的檔案        |
| `find . -empty -type f`               | 列出當前目錄下的空檔案                     |
| `find ~ -newer /etc/passwd`           | 列出家目錄內比 `/etc/passwd` 新的檔案或目錄   |
| `find /lib/ -maxdepth 1 -name "java"` | 搜尋 `/lib/` 目錄（不含子目錄）內的 `java`   |

## find 配合 -exec(find專屬參數)

利用 `find` 找出大量目標後，直接套用某個指令：

```bash
find /path/ -name "filename" -exec 指令 {} \;
# {} 表示所找到的檔案或目錄，結尾必須加上 \;
```

**範例：**

```bash
# 找出所有大於 500 MB 的檔案並刪除
find / -size +500M -exec rm {} \;

# 將 /tmp（及子目錄）內找到的 *.txt 複製到家目錄
find /tmp/ -type f -name "*.txt" -exec cp {} ~ \;
```
