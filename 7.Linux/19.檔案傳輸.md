# 檔案下載工具（wget）

`wget` 是一個從網路上下載檔案的強大工具，支援 **HTTP、HTTPS、FTP** 等網路協定。

> 📖 **官方說明手冊**：[GNU Wget Manual](https://www.gnu.org/software/wget/manual/)

### 常用選項

| 選項 | 說明 |
|------|------|
| `-r` | 遞迴下載，把網頁中所有的連結都下載回來 |
| `-N` | 只下載有更新的文件 |
| `-m` | 鏡像下載（抓取整個網站），相當於同時使用 `-r` 和 `-N` |
| `-P` | 指定下載檔案存放的目的地路徑 |
| `-c` | 設定續傳功能（若中斷可接續下載） |
| `-np` | 不下載目標目錄的上層（parent）或其他無關目錄 |
| `-A` | 接受的檔案樣式（指定副檔名） |

### 指令範例

```bash
wget http://www.google.com               # 抓取 Google 首頁
wget -m https://www.kernel.org/          # 鏡像抓取整個網站
wget -r -A "*.mp3" http://address        # 遞迴抓取該網站內所有附檔名為 mp3 的檔案
wget ftp://user:password@addr/files/     # 連線至 FTP 抓取檔案
```

# 檔案傳輸（sftp 與 scp）

## 1. 互動式傳輸（sftp）

類似傳統的 FTP 操作介面，但底層走的是 SSH 加密通道，非常安全。

**登入語法：**
```bash
sftp 對方帳號@對方主機位址
```

**進入 `sftp>` 介面後常用的內部指令：**
- `get [檔名]`：下載遠端檔案至本地**當前目錄**
- `put [檔名]`：將本地檔案上傳至遠端
- `exit`：結束 sftp 連線

### 執行範例
```
[user1@localhost tmp]$ sftp user2@192.168.0.112
user2@192.168.0.112's password: 
Connected to 192.168.0.112.

sftp> ls
test.txt  公共  圖片  文件  桌面  

sftp> get test.txt    # 下載檔案
Fetching /home/user1/test.txt to test.txt
/home/user1/test.txt         100% 3486     3.4KB/s   00:00    

sftp> exit            # 結束連線
[user1@localhost tmp]$
```

---

## 2. 單行指令傳輸（scp）

若已經知道遠端主機上的檔案確切路徑，使用 `scp` 指令會比 `sftp` 更快速直接（底層同樣為 SSH）。

**語法範例：**

```bash
# ⬇️ 【下載】：從遠端抓 test2.txt 到本地的 /tmp/
scp user2@192.168.0.112:/home/user2/test2.txt /tmp

# ⬆️ 【上傳】：將本地的 test2.txt 丟到遠端的 /home/user2/
scp test2.txt user2@192.168.0.112:/home/user2/
```

# Windows 與 Linux 之間的檔案傳輸

若是從 Windows 作業系統想要與 Linux 主機進行檔案傳輸，可使用圖形化介面（GUI）的軟體。

推薦工具：
- **FileZilla**：跨平台的 FTP/SFTP 客戶端軟體（[下載連結](https://filezilla-project.org/)）
- **WinSCP**：Windows 專用，支援 SCP 和 SFTP，操作直觀（[下載連結](http://winscp.net/)）
