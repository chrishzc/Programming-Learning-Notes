
# 簡介
- 類Unix作業系統 (Unix-like)
- 作業系統分為 類Unix 、 windows 兩代流派
- 自由(Free)及開放原始碼(Open Source)
- 可移植至多種硬體平台上，例如個人電腦、伺服器、嵌入式系統等

# 優點
- 開放原始碼
- 免費或少許費用
- ==網路服務功能強大==
- ==系統穩定可靠==
- ==安全性高==
- ==支援多人多工==
- 跨平台的移植性佳
- 圖形使用者介面多元
- 開發工具豐富

# GPL條款
- GPL通用公共授權條款 (General Public License)
- 由Richard Stallman於1989年撰寫，提供各類自由軟體使用，做為主要的授權聲明：
- 自由軟體代表使用者擁有執行、複製、散布、研究、修改、和改善軟體的自由
- 自由軟體講求自由，無關價格

# 虛擬化簡介
Host：實體主機
Guest：所模擬出的虛擬主機
- 邏輯上彼此獨立
- 每個Guest可設定不同的硬體資源(記憶體、硬碟、CPU)
- 每個Guest可安裝各自的作業系統，並且可以同時開機運行

## Oracle VirtualBox
Guest 可輕易新增、刪除、複製、快照備份、還原
- 類似軟體還有 VMware Player、微軟 Virtual PC 等
- 常用於練習及測試
