# 新增目錄（mkdir）

> ==不能產生絕對路徑相同的資料夾==

**選項：**

| 選項 | 說明 |
|------|------|
| `-p` | 自動產生路徑串中尚未存在的目錄 |

**指令範例：**

| 指令範例 | 說明 |
|----------|------|
| `mkdir dir1` | 於當前目錄內建立 `dir1` |
| `mkdir dir2 dir3` | 於當前目錄內同時建立 2 個目錄 |
| `mkdir /home/user1/dir4` | 使用絕對路徑建立目錄 |
| `mkdir -p a/b/c/` | 若 `a`、`b`、`c` 原本都不存在，自動建立整條路徑 |

# 新增檔案 / 修改時間戳記（touch）

> ==不允許建立絕對路徑相同的檔案或目錄==
> ==若指定一個已存在的檔案，會更改該檔案（目錄）被存取或修改的時間戳記（timestamp）==

**指令範例：**

| 指令範例 | 說明 |
|----------|------|
| `touch file1` | 新增 `file1` |
| `touch file2 file3 /tmp/file4` | 同時新增多個檔案 |
| `touch {1..3}.txt` | 新增 `1.txt`、`2.txt`、`3.txt` |
| `touch -t 201401020304 file1` | 將檔案時間戳記修改成 2014/01/02 03:04 |
| `touch file1` | 將 `file1` 時間戳記改成當前時間 |
| `touch dir1` | 將目錄時間戳記改成當前時間 |


# 刪除檔案或目錄（rm）

**選項：**

| 選項                          | 說明                               |
| --------------------------- | -------------------------------- |
| `-i`                        | 互動模式（interactive），刪除前向使用者確認（y/n） |
| `-f`                        | 強制刪除（force），不向使用者確認              |
| `-r` / `-R` / `--recursive` | 遞迴刪除，必須用此選項才能刪除子目錄及其檔案           |

**指令範例：**

| 指令範例 | 說明 |
|----------|------|
| `rm file1` | 刪除 `file1` |
| `rm -r dir1` | 將 `dir1` 目錄完整刪除 |

# 複製檔案或目錄（cp）

- 可使用相對路徑或絕對路徑
- 可以有多個來源（檔案或目錄），但此時目標只能是目錄

**選項：**

| 選項 | 說明 |
|------|------|
| `-r` | 遞迴（recursive）複製，用於目錄的複製 |
| `-a` | 相當於 `-p -d -r` 一起併用（常用） |
| `-p` | 連同檔案的屬性一起複製，而非使用預設屬性（備份常用） |
| `-d` | 若來源為連結檔，則複製連結檔屬性而非檔案本身 |
| `-i` | 若目標已存在，複製前向使用者確認 |
| `-u` | 更新（update），若目標較舊或不存在時才進行複製 |

**指令範例：**

| 指令範例 | 說明 |
|----------|------|
| `cp file1 file2` | 將 `file1` 複製成 `file2` |
| `cp -r dir1 dir2` | 若 `dir2` 不存在，將 `dir1` 複製為 `dir2`；若 `dir2` 已存在，把 `dir1` 複製到 `dir2` 內 |
| `cp file1 /tmp/` | 複製 `file1` 到 `/tmp/` 內 |
| `cp file1 /tmp/file2` | 複製 `file1` 到 `/tmp/` 內，並命名為 `file2` |
| `cp -a dir1/ /tmp/` | 把 `dir1` 複製到 `/tmp/` 內，並保留屬性 |
| `cp file1 file2 /tmp/` | 把 `file1` 及 `file2` 複製到 `/tmp/` 內 |
| `cp -u file1 file3` | 當 `file3` 不存在或比 `file1` 舊時才進行複製 |

# 移動檔案或目錄（mv）

- 可使用相對路徑或絕對路徑
- 可以有多個來源，但此時目標只能是目錄
- 也可用於**更改名稱**

**選項：**

| 選項 | 說明 |
|------|------|
| `-i` | 若目標已存在，移動前向使用者確認 |
| `-f` | 強制直接覆寫 |
| `-u` | 更新（update），若目標較舊才會覆寫 |
| `-n` | 不覆寫已存在的檔案 |

**指令範例：**

| 指令範例 | 說明 |
|----------|------|
| `mv file1 file2` | 將 `file1` 移動（更名）為 `file2` |
| `mv dir1 dir2` | 若 `dir2` 不存在，將 `dir1` 更名為 `dir2`；若 `dir2` 已存在，把 `dir1` 移動至 `dir2/` 內 |
| `mv file1 dir1/` | 將 `file1` 移動到 `dir1` 目錄下 |
| `mv file1 dir1/file2` | 將 `file1` 移動至 `dir1` 目錄下，並更名為 `file2` |
| `mv * ../` | 移動當前目錄下的所有檔案（及子目錄）到上一級目錄 |
| `mv -n file1 dir1/` | 不覆寫已存在的檔案 |
| `mv /tmp/file2 .` | 將 `/tmp/file2` 移動到當前目錄下 |

# 隱藏檔（或目錄）

將檔案或目錄名稱前面加上 `.` 就可將其隱藏。例如將 `file1.txt` 改名為 `.file1.txt` 就變成隱藏檔。

```bash
mv file1.txt .file1.txt   # 隱藏檔案
ls                         # 看不到隱藏檔/目錄
ls -a                      # 顯示所有檔案/目錄（含隱藏）
mv .file1.txt file1.txt   # 取消隱藏
```

# 查看檔案系統資訊（df）

> **df**：disk free

```bash
df      # 顯示所有檔案系統的資訊
df -h   # 以易懂的方式顯示大小（例如 1K、234M、5G）
```

# 檔案資訊紀錄檔（inode）

每個檔案皆有對應的 inode，用來描述：
- 檔案資訊（權限屬性、大小、更動時間等）
- 檔案儲存的區塊位置（檔案內容）

==**查詢 inode：==**

```bash
ls -i file1.txt   # 顯示 inode 編號，例如：12345
```

# 硬式連結（Hard Link）

```bash
ln 檔案 連結名稱
```

- 多個檔名同時對應到同一個檔案實體，**不會增加 inode 個數**
- 僅能用在**同一個檔案系統**中，且**只能用於檔案**（例如不能在家目錄內連結至 USB 隨身碟）
- 若實際檔案被刪除，仍然可以透過連結存取檔案

```bash
ln file1 hlink1   # 建立硬式連結 hlink1
rm file1          # 刪除 file1 後，仍然可透過 hlink1 存取檔案內容
rm hlink1         # 刪除硬式連結 hlink1
```

# 軟式連結（Soft Link）

```bash
ln -s 檔案（或目錄） 連結名稱
```

- `-s` 表示 soft link（又稱 symbolic link）
- 若實際檔案（或目錄）被刪除，則符號連結就**失效**。==可以直接連結絕對路徑避免失效==
- ==可以連結指令==達成自訂指令名稱的功能

```bash
ln -s file2 slink2   # 建立軟式連結 slink2
rm file2             # 刪除 file2 後，slink2 就失效了
rm slink2            # 刪除軟式連結 slink2
```
