# Linux 壓縮檔

> 壓縮檔的附檔名只是為了**識別**作用

| 附檔名 | 說明 |
|--------|------|
| `*.zip` | 以 `zip` 程式壓縮的檔案 |
| `*.gz` | 以 `gzip` 程式壓縮的檔案 |
| `*.bz2` | 以 `bzip2` 程式壓縮的檔案 |
| `*.xz` | 以 `xz` 程式壓縮的檔案 |
| `*.tar` | 以 `tar` 程式**打包**的檔案，**未壓縮** |
| `*.tar.gz` / `*.tgz` | 以 `tar` 打包，並以 `gzip` 壓縮 |
| `*.tar.bz2` | 以 `tar` 打包，並以 `bzip2` 壓縮 |
| `*.tar.xz` | 以 `tar` 打包，並以 `xz` 壓縮 |

---

# zip / unzip

```bash
zip file1.zip file1   # 壓縮 file1，產生 file1.zip
unzip file1.zip       # 解壓縮 file1.zip
```

---

# gzip / gunzip

> 只能壓縮**單一檔案**，無法將多個檔案壓縮為一個

```bash
gzip file1          # 壓縮後生成 file1.gz，並刪除原始檔案
gzip -9 file2       # 壓縮程度可加 1~9（預設為 6）
gzip -d file1.gz    # 解壓縮
gunzip file2.gz     # 解壓縮
```

---

# bzip2 / bunzip2（壓縮效率較佳）

```bash
bzip2 file1         # 壓縮後生成 file1.bz2，並刪除原始檔
bzip2 -k file1      # 壓縮後生成 file1.bz2，但保留原始檔
bzip2 -d file1.bz2  # 解壓縮
bunzip2 file1.bz2   # 解壓縮
```

---

# xz / unxz（壓縮效率更好）

```bash
xz file1        # 壓縮後生成 file1.xz，並刪除原始檔
xz -k file1     # 壓縮後生成 file1.xz，但保留原始檔
xz -d file1.xz  # 解壓縮，並刪除壓縮檔
unxz file1.xz   # 解壓縮，並刪除壓縮檔
```

# tar

> ==用於將多個檔案合併為一個檔案，以利備份和壓縮==

## 常用選項

| 選項 | 說明 |
|------|------|
| `-c` | 建立（打包）檔案 |
| `-x` | 解開檔案 |
| `-v` | 顯示過程 |
| `-t` | 查看內容 |
| `-f 檔名` | 要被處理的檔案名稱 |
| `-z` | 由 `gzip` 處理 |
| `-j` | 由 `bzip2` 處理 |
| `-J` | 由 `xz` 處理 |
| `-C 目的路徑` | 指定解開的目的地路徑 |

## 打包並壓縮

```bash
tar -cf dir1.tar dir1       # 將 dir1 下所有檔案合併成 dir1.tar（未壓縮）

# 打包並壓縮成不同格式
tar -zcf test.tar.gz dir1   # gzip 壓縮
tar -zcf test.tgz dir1      # gzip 壓縮（.tgz 格式）
tar -jcf test.tar.bz2 dir1  # bzip2 壓縮
tar -Jcf test.tar.xz dir1   # xz 壓縮
```

## 查看內容（不解開）

```bash
tar -tvf test.tar.gz   # 只顯示內容物，未真實解開
```

## 解開壓縮檔

```bash
tar -zxf test.tar.gz              # 解開 gzip 壓縮的 tar
tar -zxf test.tgz                 # 同上（.tgz 格式）
tar -zxf test.tar.gz -C /tmp      # 解開並放到 /tmp/ 下
tar -jxf test.tar.bz2             # 解開 bzip2 壓縮的 tar
tar -Jxf test.tar.xz              # 解開 xz 壓縮的 tar
```
