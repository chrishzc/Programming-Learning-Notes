# NAT 網路實驗 [Windows / VirtualBox]

此實驗的目的為準備兩台 Linux 主機，並放置於同一個「NAT 網路」下，使它們能互相連線。

### 操作步驟

1. **建立虛擬機器**：
   - 利用 VirtualBox 的「再製（Clone）」功能，新增一台 Linux。
   - **注意**：設定 MAC 位址原則時，請選擇**「為所有網路卡產生新的 MAC 位址」**，避免網路衝突。
2. **建立 NAT 網路**：
   - 點選 VirtualBox 主介面的 `工具` -> 開啟 `網路`。
   - 在右方選擇 `NAT Networks`，然後點選 `建立`。
3. **更改虛擬機網路設定**：
   - 分別將兩台 Linux 的網路設定模式從「NAT」改為「NAT 網路」。
   - 操作路徑：虛擬機按右鍵選擇 `設定` -> `網路` -> 附加到：選擇 `NAT 網路` -> 名稱選擇剛剛建立的（例如 `NatNetwork`）。
   - 完成後將兩台虛擬機開機。

# 顯示連線是否建立（ping）

傳送網路封包至對方主機（ICMP 封包），測試是否可連線。

```bash
ping www.google.com          # 持續測試，需以 Ctrl+C 中斷
ping -c 3 www.google.com     # 加上 -c 參數，只測試 3 次
```

### 封包執行結果說明

```
user1@Vbox:~$ ping -c 3 www.google.com
PING www.google.com (210.61.221.178) 56(84) bytes of data.
64 bytes from 210-61-221-178.HINET-IP.hinet.net (210.61.221.178): icmp_req=1 ttl=128 time=2.29 ms
64 bytes from 210-61-221-178.HINET-IP.hinet.net (210.61.221.178): icmp_req=2 ttl=128 time=2.06 ms
64 bytes from 210-61-221-178.HINET-IP.hinet.net (210.61.221.178): icmp_req=3 ttl=128 time=2.16 ms

--- www.google.com ping statistics ---
3 packets transmitted, 3 received, 0% packet loss, time 2004ms
rtt min/avg/max/mdev = 2.061/2.175/2.296/0.103 ms
```

> **TTL（Time To Live，存活時間）**
> - 指一個封包在通過網路時，最長可以逗留的時間（通常用跳數計算）。
> - 封包每經過一個路由器，TTL 減 1；當 TTL 為 0 時，路由器便會丟棄該封包，避免封包在網路上無限迴圈。

# SSH 遠端登入 Linux

SSH 是一種加密的網路協定，常用來進行遠端主機的安全連線操作。

### 安裝與連線

| 動作 | 指令/軟體 | 說明 |
|------|-----------|------|
| **安裝 SSH 伺服器** | `sudo apt install -y openssh-server` | 若要被遠端連線，本機必須安裝並啟動 ssh server |
| **遠端連線指令** | `ssh 帳號@遠端主機IP` | 會要求輸入遠端主機的密碼 |
| **Windows 連線工具** | **PuTTY**、**PieTTY** 或 **Windows Terminal** | Windows 使用者可透過這些終端機軟體進行 SSH 連線 |

# SSH 登入免輸入密碼（金鑰認證）

透過產生「公鑰與私鑰」來達成免密碼安全登入。

```mermaid
flowchart LR
    A["💻 Client 端\n產生 Key-Pair"] -->|"上傳公鑰"| B["🖥️ Server 端\n存放公鑰 (authorized_keys)"]
    A -.->|"連線時出示私鑰"| B
    B -.->|"驗證通過，免密碼放行"| A
```

### 設定步驟

1. **產生 Key-Pair（公鑰+私鑰）**
   ```bash
   ssh-keygen
   ```
   > 執行後一直按 `Enter` 使用預設值即可。

2. **將公鑰上傳到 Server 端**
   ```bash
   ssh-copy-id user1@10.0.2.15
   ```
   > 上傳時需要輸入最後一次密碼。之後即可直接以 `user1` 免密碼登入該 Server。

# 檢視本機的網路連線狀況（ss）

`ss` 指令用來查詢目前有哪些網路連線與本機建立，或本機開啟了哪些 Port。

### 常用選項

| 選項 | 說明 |
|------|------|
| `-a` | 顯示所有網路埠（sockets） |
| `-n` | 以數字顯示位址與 Port（不反查 DNS），**速度較快** |
| `-t` | 僅顯示 TCP 連線 |
| `-u` | 僅顯示 UDP 連線 |
| `-l` | 僅顯示正在監聽（listening）的網路埠 |
| `-p` | 顯示佔用該連線的 **PID / 行程名稱**（需 root 權限） |

### 指令範例

| 指令 | 說明 |
|------|------|
| `ss -na \| less` | 以數字顯示所有網路通訊 |
| `ss -nat \| less` | 以數字顯示所有 **TCP** 網路通訊 |
| `ss -nat \| grep "ESTAB"` | 顯示所有**已經建立**（ESTABLISHED）的 TCP 連線 |
| `ss -nat \| grep :443` | 顯示所有與 Port 443（HTTPS）相關的 TCP 連線 |
| `sudo ss -tulnp \| less` | 檢視目前已經啟動監聽的網路服務及對應 PID |

### 連線情境範例

當執行 `ss -nat | less` 時，可以觀察：
- **遠端連線進來**：遠端主機（`10.0.2.15`）連線到本機（`10.0.2.7`）的 Port 22 (SSH)。
- **本機對外連線**：本地端主機連線到外部網路的服務（例如向外發起 HTTPS 請求，連接到外部的 `443` Port）。
