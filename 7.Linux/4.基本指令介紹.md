# Linux 指令格式

大多數的指令都設計為支援 0 個至多個「選項」或「參數」，各欄位間以**空白**或 **Tab** 作為分隔符號（分隔符號數量不影響結果）。

```
指令 [選項]... [參數]...
```

| 欄位 | 角色 | 說明 |
|------|------|------|
| 指令 | 動詞 | 你想做的動作；為內建或已安裝的可執行檔，名稱皆小寫 |
| 選項 | 副詞 | 指令的功能變化；分短選項（`-h`）與長選項（`--help`） |
| 參數 | 受詞 | 指令或選項的目標，可能是檔案、目錄、帳號等字串 |

# echo

印出字串至標準輸出。

```bash
echo test           # 印出 test
echo -n test2       # 印出 test2 後不換行
echo $PATH          # 印出環境變數 PATH 的值
echo "hello world"  # 依字串原樣輸出（保留空白）
echo hello world    # 空白視為 2 個字串，以一個空格區隔
echo '
12345
67890
'                   # 單引號可一次輸出多行
```

> ==字串可用引號標注==
> ==(Python 預設 不加""指的是函式名稱，Linux 預設如果不是函式或變數就當作是字串)==

# 切換所在目錄（cd）

> **cd**：Change Directory

| 指令範例 | 說明 |
|----------|------|
| `cd /` | 切換至根目錄 |
| `cd /tmp/` | 切換至 `/tmp` 目錄 |
| `cd /usr/lib/` | 切換至 `/usr/lib` 目錄 |
| `cd /home/user1/` | 切換至 `/home/user1` 目錄 |
| `cd ~` 或 `cd` | 切換至帳號的家目錄 |
| `cd ..` | 切換至上層目錄 |
| `cd ../../` | 切換至上上層目錄 |
| `cd -` | 切換至上次所在的路徑 |

# 清除螢幕畫面（clear、reset）

| 指令 | 說明 |
|------|------|
| `clear` | 清除終端機畫面（過往訊息仍可用滑鼠往上捲動顯示） |
| `reset` | 重新初始化螢幕（過往訊息**無法**用滑鼠往上捲動顯示） |

# 查詢指令操作歷史紀錄（history）

以 bash 登入後，bash 會自動從 `~/.bash_history` 讀取此帳號過去的指令紀錄，並於登出時寫入檔案。預設上限 **1000 筆**。

```bash
history [N]   # N 為顯示筆數
```

| 指令範例 | 說明 |
|----------|------|
| `history` | 列出所有指令操作紀錄 |
| `history 5` | 列出最近 5 筆指令操作紀錄 |
| `history -c` | 刪除全部紀錄 |
| `history -d 2` | 刪除編號 2 的指令紀錄 |
| `!!` | 執行上一個指令（相當於按 ↑ 後執行） |
| `!wh` | 執行上一個名稱為 `wh` 開頭的歷史指令 |
| `!5` | 執行編號第 5 個指令紀錄 |
| `!-6` | 執行倒數第 6 個指令紀錄 |

# 檢視目錄或檔案資訊（ls）

```bash
ls        # 顯示當前目錄內容
ls -l     # 以詳細資訊方式顯示當前目錄內容
```

## 常用選項

| 選項 | 說明 |
|------|------|
| `-a` | 也顯示隱藏檔（`--all`） |
| `-l` | 以詳細資訊方式顯示 |
| `-h` | 以易懂的方式顯示檔案大小 |
| `-d` | 顯示目錄本身，而非其包含的檔案清單 |
| `-r` | 反向排序顯示（`--reverse`） |
| `-S` | 依檔案大小排序顯示 |
| `-t` | 依修改時間排序顯示 |

## 指令範例

| 指令範例 | 說明 |
|----------|------|
| `ls /bin/` | 顯示 `/bin/` 內的檔案（子目錄）清單 |
| `ls -l /etc/passwd` | 顯示該檔案的屬性（日期、大小等） |
| `ls -a -l -h /home/user1` | 等同 `ls -alh /home/user1` |
| `ls -l -d /home/user1` | 顯示目錄本身的詳細資訊 |

# 查詢指令用法

## man（操作手冊）

```bash
man <指令名稱>   # 例如：man ls
```

- `[ ]` 表示該欄位可以有 0 個或 1 個
- `…` 表示該欄位可以有 1 個以上

**操作方式：**

| 按鍵 | 功能 |
|------|------|
| `h` | 顯示說明 |
| `PageUp` / `PageDown` | 上下翻頁 |
| `/` | 進行字串搜尋 |
| `n` | 往下繼續搜尋 |
| `N` | 往上繼續搜尋 |
| `q` | 結束離開 |

## info 及 whatis

| 指令 | 說明 |
|------|------|
| `info <指令名稱>` | 結果較多文字型敘述，例如：`info ls` |
| `whatis <指令名稱>` | 結果非常簡潔，例如：`whatis ls` |

## 指令自帶說明

```bash
<指令> --help   # 多數（但非全部）指令皆提供此選項
# 例如：ls --help
```
