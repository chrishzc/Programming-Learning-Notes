# 帳號（User）

- 帳號名稱是**唯一的、不可重複**，且大小寫有別
- 命名規則：
  - 組成可以為字母、數字、底線、`-` 或 `.`
  - 開頭必須是字母或 `_`
  - 中間不能留有空白字元

## 帳號編號（UID）

每個帳號會對應一個不重複的編號（User ID，簡稱 UID）：

| UID 範圍 | 身分 | 範例 |
|---------|------|------|
| `0` | root | `root` |
| `1 ~ 999` | 系統服務帳號 | `cdrom`、`daemon` |
| `1000 ~ 65535` | 一般使用者 | `user1 (1000)`、`user2 (1001)` |

---

# root 帳號

- 擁有最高權限的系統管理員，可任意讀取、修改、刪除檔案或目錄及設定系統
- 家目錄為 `/root/`
- UID 是 `0`，GID 也是 `0`
- Shell 提示符號為 `#`

> 儘量少用 root 帳號登入，減少因手誤而損壞系統的風險

---

# 帳號相關的設定檔

| 設定檔 | 說明 |
|--------|------|
| `/etc/passwd` | 記錄系統帳號相關資訊 |
| `/etc/shadow` | 記錄使用者帳號密碼相關資訊 |

## /etc/passwd

每行代表一個帳號，以 `:` 分隔以下欄位：

```
user1 : x : 1000 : 1000 : user1,,, : /home/user1 : /bin/bash
  1      2    3      4        5            6               7
```

| 欄位 | 說明 |
|------|------|
| 1 | 使用者帳號（1~32 字元） |
| 2 | 密碼（顯示 `x` 表示已改存於 `/etc/shadow`） |
| 3 | 帳號的 UID |
| 4 | 帳號所屬主要群組的 GID |
| 5 | 此帳號的備註 |
| 6 | 家目錄的路徑 |
| 7 | 使用者登入後預設的 Shell |

## /etc/shadow

每行代表一個帳號，以 `:` 分隔以下欄位：

```
user1 : $1$VM7t54w3$EoDTTR... : 15972 : 0 : 99999 : 7 : : :
  1              2                 3     4     5      6   7  8  9
```

| 欄位 | 說明 |
|------|------|
| 1 | 帳號名稱 |
| 2 | 加密後的密碼 |
| 3 | 密碼最後改變的日期（從 1970/01/01 起算） |
| 4 | 密碼不可被更動的天數（相對於第 3 欄） |
| 5 | 這組密碼還有多久會過期（相對於第 3 欄） |
| 6 | 警告更改密碼間隔天數（相對於第 5 欄） |
| 7 | 密碼過期後帳號還有多久會解除（相對於第 5 欄） |
| 8 | 帳號還有多久會過期（從 1970/01/01 起算） |
| 9 | 保留欄位 |

# sudo

```bash
sudo 指令   # 暫時用 root 權限執行該指令，執行完畢後權限立即消失
```

- 使用時必須輸入**目前帳號**的密碼，以驗證身分
- 每次密碼可維持 **5 分鐘**內不需再輸入
- 好處：易於管理、只在必要時才給予 root 權限，提升安全性

## 授權使用 sudo

只有寫於 `/etc/sudoers` 設定檔內的帳號才可以使用 `sudo`，以 `visudo` 編輯（存檔前會做語法檢查）：

```bash
sudo visudo
```

```
root  ALL=(ALL) ALL   # 原有的一行
user2 ALL=(ALL) ALL   # 新增這行，讓 user2 擁有 sudo 權力
```

## sudo（wheel）群組

只要加入 `sudo` 群組，就有資格使用 `sudo`：

```bash
sudo usermod -aG sudo user3   # 將 user3 的次要群組設定為 sudo
```

# 更改帳號密碼（passwd）

```bash
passwd [帳號]   # 不指定帳號則預設更改目前帳號的密碼
```

- 以 root 權限更改他人密碼，不需輸入原始密碼
- Ubuntu 預設沒有 root 密碼，必須先用 `sudo` 幫 root 設定密碼才能切換成 root
- 新密碼若設定太簡單，會被系統拒絕

---

# 切換帳號（su）

```bash
su [帳號]   # 預設切換成 root
```

- 切換後會產生新的子 Shell 讓新帳號使用
- 要返回原帳號可使用 `exit`（結束子 Shell）

| 指令 | 說明 |
|------|------|
| `su - root` | 切換成 root，使用 root 的 mail 與環境變數設定（**login-shell**） |
| `su root` | 切換成 root，使用原帳號的 mail 與環境變數設定 |
| `exit` | 返回原帳號 |

## 切換成 root 的第二種方式

```bash
sudo -i   # 不需輸入 root 密碼，而是輸入自身密碼
exit      # 切換回原本帳號
```

---

# 新增帳號（adduser）(有UI可以用UI設定)

```bash
adduser 帳號名稱   # 需 root 權限
```

- 會在 `/etc/passwd` 內新增一行帳號紀錄
- 自動新增一個同名的群組
- 建立該帳號的家目錄、信件夾
- 以互動模式輸入密碼

> 若希望用腳本（非互動模式），可改用 `useradd`

---

# 修改帳號（usermod）(有UI可以用UI設定)

```bash
usermod [選項] 帳號   # 需 root 權限
```

**選項：**

| 選項 | 說明 |
|------|------|
| `-u` / `--uid UID` | 設定新 UID |
| `-d` / `--home HOME_DIR` | 設定家目錄 |
| `-g` / `--gid GROUP` | 設定主要群組 |
| `-G` / `--groups GROUPS` | 設定次要群組 |
| `-a` / `--append` | 附加次要群組（與 `-G` 搭配使用） |
| `-L` / `--lock` | 鎖定帳號 |
| `-U` / `--unlock` | 解鎖帳號 |

**指令範例：**

| 指令範例 | 說明 |
|----------|------|
| `sudo usermod -g user1 user3` | 將 `user3` 的主要群組變更為 `user1` |
| `sudo usermod -g user3 user3` | 將 `user3` 的主要群組變更為 `user3` |
| `sudo usermod -G user1 user3` | `user3` 的次要群組設定成 `user1` |
| `sudo usermod -aG group2 user3` | `user3` 的次要群組新增 `group2` |
| `sudo usermod -L user3` | 鎖定 `user3`（無法登入） |

---

# 刪除帳號（userdel）(有UI可以用UI設定)

```bash
userdel -r -f user3   # 強制刪除 user3（含家目錄）
```

> 若只是暫時不用該帳號，建議只**鎖定**，不需刪除

---

# 查詢帳號所屬群組（id / groups）

```bash
groups user1             # user1 : user1 wheel
id user1                 # uid=1000(user1) gid=1000(user1) groups=1000(user1),10(wheel)
id -u user1              # 只印出 UID：1000
id -G user1              # 印出此帳號所有群組 ID：1000 10
```

---

# 顯示系統登入紀錄（last）

```bash
last                 # 顯示所有登入紀錄
last -n 3            # 顯示最近 3 筆紀錄
last user1           # 只顯示 user1 的登入紀錄
last reboot          # 顯示重開機的紀錄
```

# 群組（Group）

==群組設計目的：方便管理系統、資源共享以及隱私安全性保護（例如讓某個檔案只允許被某個群組的成員存取）。==

## 群組編號（GID）

每個群組會對應一個不重複的編號（Group ID，簡稱 GID）：

| GID 範圍 | 群組身分 | 範例 |
|---------|---------|------|
| `0` | root 群組 | `root` |
| `1 ~ 999` | 系統服務群組 | `cdrom`、`daemon` |
| `1000 ~ 65535` | 一般群組 | `user1 (1000)`、`user2 (1001)` |

## 主要群組與次要群組

**主要群組：**
- ==一個帳號只能擁有**一個**主要群組==
- ==帳號若沒有主要群組，則**無法登入**==
- 新增帳號時，預設會指定一個與帳號**同名**的主要群組
- 用來判斷檔案/目錄的群組權限

**次要群組：**
- 一個帳號可以擁有 0 至多個次要群組

---

# 群組相關的設定檔

| 設定檔 | 說明 |
|--------|------|
| `/etc/group` | 記錄各使用者屬於哪個群組 |
| `/etc/gshadow` | 記錄群組密碼相關資訊 |

## /etc/group

一行代表一個群組，以 `:` 分隔共 4 個欄位：

| 欄位 | 說明 |
|------|------|
| 1 | 群組名稱 |
| 2 | 群組密碼（顯示 `x` 表示已改存於 `/etc/gshadow`） |
| 3 | GID |
| 4 | 這個群組的會員 |

## /etc/gshadow

一行代表一個群組，以 `:` 分隔共 4 個欄位：

| 欄位 | 說明 |
|------|------|
| 1 | 群組名稱 |
| 2 | 加密後的群組密碼 |
| 3 | 群組管理員帳號 |
| 4 | 這個群組的會員 |

---

# 新增 / 修改 / 移除群組

> 以下指令皆需 root 權限

```bash
groupadd group1              # 新增 group1
groupadd -g 1004 group2      # 新增 group2，並指定 GID 為 1004
groupmod -g 1005 group2      # 修改 group2 的 GID 為 1005
groupmod -n newgroup group2  # 將 group2 改名為 newgroup
groupdel group1              # 刪除 group1（若仍有主要群組成員則無法刪除）
```

| 指令                      | 說明   |
| ----------------------- | ---- |
| `groupadd [-g gid] 群組名` | 新增群組 |
| `groupmod [-n 新名稱] 群組名` | 修改群組 |
| `groupdel 群組名`          | 刪除群組 |
